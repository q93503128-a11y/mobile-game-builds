# Mobile Game Builds

문승준의 모바일 게임 프로젝트를 한 저장소에서 관리하는 공용 모노레포입니다.

## 고정 저장소 구조

```text
mobile-game-builds/
├─ README.md
├─ RULES.md
├─ .gitignore
├─ docs/
│  └─ REPOSITORY_STRUCTURE.md
├─ projects/
│  └─ <project-id>/
│     ├─ README.md
│     ├─ docs/
│     ├─ client/
│     ├─ server/
│     ├─ data/
│     ├─ tools/
│     └─ tests/
└─ shared/
   └─ README.md
```

이 구조는 공용 규칙으로 고정한다. 프로젝트별 임시 편의에 따라 루트 구조를 무단 변경하지 않는다.

## 현재 프로젝트

현재 등록된 프로젝트가 없습니다.

## 정본 우선순위

1. 현재 `main`의 실제 코드와 데이터
2. 각 프로젝트의 `docs/DESIGN_BIBLE.md`
3. 각 프로젝트의 세부 시스템 문서
4. 공용 `RULES.md`
5. 과거 인계문/채팅 요약

코드와 문서가 충돌하면 현재 동작을 확인한 뒤 같은 커밋에서 정합성을 복구한다.

## 개발 원칙 요약

- 완성도 우선, 임시 땜질 누적 금지
- 죽은 코드·중복 코드·임시 우회·사용되지 않는 리소스는 발견 즉시 정리
- 기능 변경 시 관련 테스트와 정본 문서를 같은 작업에서 동기화
- 모바일 입력·가독성·성능·화면 크기를 PC 기준보다 우선
- 수치 밸런스는 검증된 동종 모바일 게임 자료를 조사해 비교한 뒤 프로젝트 구조에 맞게 변형
- 결제·가챠·랭킹·계정·길드·채팅 등 서버 권위가 필요한 시스템을 클라이언트 신뢰 방식으로 구현하지 않음
- 외부 게임의 이름·아트·문구·고유 자산·수치를 그대로 복제하지 않고 검증된 시스템 원리와 범위를 참고해 재설계

세부 규칙은 [`RULES.md`](./RULES.md)를 따른다.
