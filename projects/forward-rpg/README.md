# 전진형 개인 RPG (가제 · 프로젝트 ID: forward-rpg)

**상태:** 프리프로덕션 / 기획 중 (2026-11-11 기준). **세계관 방향은 마법과 기술이 공존하는 고대 문명 탐사로 확정**, 일반 모험가 주인공·낮은 스토리 밀도 채택. 게임명·상용화 방식과 세부 지역/아트스타일은 미정. 이 폴더는 기획 문서를 우선 보존하며, 아직 Godot 클라이언트 소스는 생성하지 않았다.

## 게임 방향
Godot 기반 모바일 2D 횡스크롤 전진형 RPG를 구상한다. 주인공 1명이 적이 없으면 자동 전진하고, 적을 만나면 멈춰 자동 기본 공격을 수행한다. 플레이어는 액티브 스킬로 개입한다. 몬스터 처치 골드로 탐험 내 성장을 하고, 별 등급의 수집품(임시 명칭 '유물')으로 영구 성장한다.

영감의 1순위는 **Rogue with the Dead(환생용병단)**의 전진·성장·지역별 수집 구조다. 복제보다는 개인형 전투에 맞춘 독립적인 구현을 목표로 한다. Idle Slayer의 길 위 코인·점프/러너 요소, 환생용병단의 시간 경과형 퀘스트 수익은 현재 방향에서 제외한다.

## 작업 원칙
1. 새 채팅/에이전트 작업 시작 시 최신 `main`과 위 문서를 읽는다. 문서 간 충돌은 `DESIGN_BIBLE.md`에 맞춰 정리한다.
2. 확정되지 않은 공식, 금액, 콘텐츠, UI, 기능을 임의로 확정하지 않는다.
3. 외부 게임을 먼저 검증하고, 확인된 사실 / 유추 / 우리 게임 제안을 구분한다.
4. 공용 [RULES.md](../../RULES.md)와 [저장소 구조 계약](../../docs/REPOSITORY_STRUCTURE.md)을 따른다.
5. 향후 코드는 `client/`, 정적 수치는 `data/`, 검증은 `tests/` 등 공용 계약의 위치에 작성한다. 현재 불필요한 빈 폴더는 만들지 않는다.
