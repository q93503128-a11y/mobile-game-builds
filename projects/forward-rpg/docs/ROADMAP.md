**상태:** 초기 기획. 아래는 '의사결정 순서'로서, 프로토타입·조사는 앞 단계와 병행 가능하다. 임의로 스탯 강화 비용이나 아트 제작부터 확정하지 않는다.

## 운영 원칙
1. 새 기획 논의의 시작에 **현재 단계와 아직 풀지 못한 이전 단계의 의문**을 확인한다.
2. 원작 환생용병단에서 해당 시스템의 실제 구현을 우선 조사하되 최신성·공식/비공식을 구별한다.
3. 각 결정은 `확정` / `방향 합의` / `검토` / `제외`로 구분하고 `DESIGN_BIBLE.md`에 반영한다.
4. 단계가 완결되지 않았으면 '완료'로 표기하지 않는다. 후속 단계 이야기는 메모만 해 두고 앞 단계로 돌아올 수 있다.
5. 사용자 승인 없이 기술 구현, 보상 수치·강화 비용, 아트 디자인, 스토리를 임의 확정하지 않는다.
6. 가능하면 '이 시스템이 왜 재미있는지'를 실제 작은 프로토타입으로 검증한다. 프로토타입을 만들었다고 본격 제작이 승인된 것은 아니다.

## 우선 보완할 사항 — 세계관/게임 정체성

**세계관 큰 방향은 고대 문명 탐사, 문명 성격은 마법과 기술이 공존한 혼합형으로 확정**했다. 주인공은 **평범한 모험가**로 정했다. **스토리는 동종 전진형/방치형 RPG처럼 낮은 밀도의 선택적 배경 설정으로 제한**하고, 유적 배경·몬스터·보스·유물 명칭/짧은 설명을 통해 암시한다. 필수 긴 컷신·연속 대사·스토리 퀘스트로 핵심 진행을 막지 않는다. 이제 모험가의 상세 과거/탐험 동기·문명의 멸망사와 상세 연대기를 선행 필수 결정으로 취급하지 않는다. 구체적인 지역/수호자/유물 연결과 시각적 톤은 5~6단계에서 게임성을 위해 필요한 범위만 설계한다. '상자/유물' 명칭은 임시로 유지한다.

## 2단계 핵심 플레이 루프 — 정책 수준 합의 완료
- **새 방향 기록:** 일반 환생은 기본 0m 재출발이며 **시작 거리 사용자 선택 확정**(계정 최고 도달 거리 및 영구 해금 범위 안에서 선택, 정확한 해금 수치·비용 미정). **특수 환생은 보석을 소비해 환생 재화를 수령하면서 거리·골드·골드 강화 등 모든 기존 상태를 그대로 유지하는 것으로 확정**했다. 특수 환생 연속 사용 허용과 사용마다 보석 비용 증가(B안)는 확정이다. 정확한 보석 가격·증가 곡선·광고 보상 중첩은 4단계 경제 검증 과제다. **일반 환생 첫 기능 해금은 월드 100m 도달로 확정**. 환생은 조건을 만족하면 자유 선택. 시작 골드 영구 강화는 후보. 환생 거리/횟수 마일스톤은 검토 중.
- **한 번의 탐험은 언제 시작하고 언제 종료되는가?** 일반 환생은 기본 0m 시작 또는 허용된 시작 거리 선택. **환생 실행 조건은 해당 회차 최고 월드 거리 `M>=100m`이고, 거리 기반 환생 재화 지급 조건은 `M-S>=100m`**다. 미달해도 **0 보상으로 일반 환생**할 수 있다. 지급액은 조건 충족 시 `max(0,F(M)-F(S))`로 계산해, 어디서 출발하든 같은 절대 거리 구간은 같은 기여 보상을 준다. 구체 곡선 수치는 4단계에서 검증. 특수 환생의 연속 사용·보석 비용 증가(B안)는 확정이며 구체적인 가격 곡선과 보상 중첩 계산은 4단계 경제 검증 과제. 부스트 발동·중첩도 미정.
- **진행 거리와 보스 재통과 [방향 확정]:** 보스는 **등간격일 필요 없이 개별 고정 거리**에 놓인다. 미처치 보스는 패배 후 돌아가면 최대 HP로 재전투, 같은 탐험에서 **이미 처치한 보스 위치는 해당 구역 일반 몬스터로 대체**해 후퇴 후 재전진 시 반복 골드 파밍 가능. 정확한 고정 보스 거리·지역 경계와 적정 정체 시간은 미정. 일반 환생에서 회차별 보스 처치 상태 초기화 및 시작 거리 이전 보스의 출발 시 자동 처치·자동 보상 없음, 별도 체크포인트 미도입은 확정. 후퇴 후 실제로 이전 보스 위치를 재통과하면 미처치 보스와 정상 전투한다.
- **사망 후 후퇴는 어떤 비용을 발생시키며, 현재 탐험 진행 상태는 무엇이 유지되는가?** 로그형 후퇴는 방향 확정(`100×ln(1+d/1000)`은 임시 시험식), **부활 HP 전량 회복·골드/골드 강화 유지·일반 몬스터 재등장/재수익·보스 재도전 시 HP 전량 초기화·강제 환생 없음은 확정**. 별도 체크포인트는 도입하지 않는다. 선택 시작 거리 이전으로 후퇴 가능하며 그 구간의 일반 몬스터 재사냥에 추가 제한을 두지 않는다. 부활 지연과 상세 전투 재등장 타이밍은 3단계에서 검증.
- **플레이어가 더 강해져야 하는 단기/장기 목표는 무엇인가?** 현재 단기 목표는 다음 고정 보스 돌파, 장기 목표는 더 먼 거리/유물·영구 성장이라는 방향이 확정. 세부 콘텐츠는 4~5단계 이관.
- **골드, 수집 보상, 영구 성장이 '다음 탐험'으로 어떻게 연결되는가?** 일반 환생에서 현재 위치·회차별 보스 상태·보유 골드·골드 강화는 초기화하고, 유물·미개봉 상자·보석·환생 재화·영구 강화·계정 최고 거리·도감은 유지한다. 환생 재화 계산 계수·영구 강화 경제는 4단계에서 검증한다.

- **체크포인트·일반 환생 보스 상태 [확정]:** 사망 후 로그형 후퇴를 사용하며 별도 체크포인트 없음. 일반 환생 때 회차별 보스 처치 상태 초기화. 시작 거리 이전의 보스는 출발 시 자동 보상 없이 건너뛰지만, 후퇴 후 해당 위치를 재통과해 실제로 격파하면 일반 보스 보상을 받을 수 있다. 계정 최고 기록·도감은 회차별 보스 플래그와 분리. 사망 시 시작 거리보다 뒤로 후퇴해도 일반 몬스터 재사냥을 허용하며, 건너뛰었던 미처치 보스도 실제 재통과 시 정상 등장한다. 부활 지연은 미정.
- **상자 획득·개봉 [합의]:** 고정 거리 보스를 격파해 상자를 얻고, 원작처럼 **상자를 보관·누적해 개별/일괄 개봉**하는 방향. 보스/지역별 상자 등급·유물 풀, 드롭 확률·개수, 개봉 UX와 귀환 보상 결산은 4단계에서 정한다. **'상자'와 '유물'은 현재 임시 명칭**이다.
- **보스 장기 교착 [테스트 후 재검토]:** 지금은 보스에게 죽지도 못하고 이기지도 못하는 상황에 전용 퇴각 기능을 추가하지 않는다. 월드 거리 100m 이상에서 보상 없이도 일반 환생할 수 있으므로 고거리 시작 시 100m 전진 이전 보스에 막혀도 리셋 가능하다. **첫 100m 이전 교착**이나 반복 환생 후 시작 구간 밸런스는 프로토타입에서 검증하고 문제가 재현되면 고친다.
- **오프라인 AFK 수익 [기본 시간·광고 확정]:** 앱 종료 중에도 몬스터 가상 사냥으로 골드 수익 정산. **기본 누적 상한 1시간**, 영구 업그레이드 등으로 연장(절대 상한·비용 미정). 광고 없이 기본 골드 수령, 선택 광고로 해당 정산 골드 **×2**. 거리 진행·보스 처치·상자 획득·환생 재화 자동 지급 없음. 온라인 골드 대비 효율 약 70%는 시험 제안일 뿐 미확정.
- **튜토리얼 [도입 방향 확정]:** 처음부터 긴 강제 연출을 넣지 않고 첫 강화/스킬 사용을 짧게 유도하는 반강제 학습, 첫 상자/환생에 문맥별 안내. 구체 화면/길이는 6단계 UX에서 정한다.
위 다섯 질문의 방향이 결정되기 전에 레벨당 골드 비용·보스 거리·유물 드롭 확률 등을 먼저 확정하지 않는다.

## 향후 GitHub 정리
- `main` 기획 정본 우선.
- 새 개발 콘텐츠가 생기면 원래 계약에 따라 `client/`, `data/`, `tools/`, `tests/`를 필요할 때 생성한다.
- 세부 시스템은 복잡도가 실제 커졌을 때만 문서로 분리한다. 불필요한 다중 정본을 만들지 않는다.
