## 1. 기본 정체성
- **장르/형태 [방향 합의]:** 모바일용 Godot 2D 횡스크롤 전진형 RPG. 개인 주인공 중심.
- **핵심 재미 [방향 합의]:** 더 먼 곳으로 전진하는 성장감 + 전투 중 직접 스킬 개입 + 희귀 수집품 발견/중복 누적/도감/한꺼번에 보상 확인.
- **주요 참고작 [확정]:** `Rogue with the Dead(환생용병단)`을 원작 시스템 조사 **1순위**로 삼는다. 기능·수치·명칭·아트·UI를 그대로 복제하지 않는다.
- **세계관 큰 방향 [확정]:** **고대 문명 탐사 + 마법과 기술이 공존했던 초고대 문명(혼합형)**. 잊힌 문명의 흔적과 유산을 찾아 먼 거리로 나아가는 탐험 RPG를 기본 테마로 삼는다. 고대 문명에는 **마법적 유산과 기술적 장치가 모두 존재**하며, 보스·유물·지역 디자인의 표현 범위를 넓힌다. 단, 마법과 기술의 관계, 문명의 멸망 이유, 주인공의 자세한 배경·전진 목적, 시대·미술 스타일·세부 지역·보스 정체는 **아직 결정하지 않는다**. 기존 게임 플레이 구조는 변경하지 않는다.
- **주인공 정체 [확정]:** 과도한 특별 혈통·선택받은 영웅 설정 없이, **고대 문명을 탐험하는 일반적인 모험가**를 주인공으로 둔다. 구체적 외형, 과거와 탐험 동기는 꼭 설명할 필요가 없으며, 상세 성장 서사를 강제하지 않는다.
- **스토리 밀도·전달 방식 [확정]:** 동종 전진형/방치형 RPG 수준의 **가볍고 비강제적인 배경 서사**를 지향한다. 세계관은 유적 배경·지역 변화·적/보스 디자인·유물 이름과 짧은 설명 등으로 자연스럽게 암시하며, 관심 있는 플레이어만 더 읽어도 이해되는 정도로 둔다. 긴 강제 컷신, 필수 대화 연속, 스토리 퀘스트를 진행 관문의 기본 조건으로 삼지 않는다. **전투·성장·수집·환생 루프가 우선**이고, 별도 정교한 연대기·세계관 설명·주인공의 운명 서사는 제작 필수 요소가 아니다. 구체적인 문명 역사나 설정은 추가 결정 전까지 확정하지 않는다.
- **프로젝트 ID:** `forward-rpg`는 임시 식별자. 최종 게임명, 주인공의 상세 설정·전진 목적, 아트스타일, 수익화 정책 **미정**. '상자'·'유물'은 고대 문명 탐사와 어울리는 임시 명칭으로 유지하되, 최종 표기 여부는 후속 네이밍 때 결정한다.
- **다국어화 개발 전략 [확정]:** **테스트 버전까지는 한국어·영어 두 언어만 지원**한다. 정식 출시 때는 다양한 언어를 폭넓게 추가할 예정이나 구체 언어 목록·우선순위·최종 출시 범위는 나중에 결정한다. **지금부터 모든 게임 문구는 코드/씬에 직접 하드코딩하지 않고 안정적인 번역 키와 별도 번역 데이터로 관리**하여, 출시 전 일괄 번역 파일 추가만으로 다국어를 확장할 수 있게 한다. 동적 문구의 변수 자리표시자, 숫자/복수형, 글꼴 및 세로·가로 화면에서 번역 길이 변화에 대응하도록 설계한다. 초기부터 여러 언어의 실제 번역을 대량 제작·검수하는 일은 하지 않는다. 영어를 원문/미지원 언어의 폴백으로 사용하는 방향은 유지하되, 최초 기기 언어 자동 감지·설정 전환 UX와 언어별 품질 검증은 구현 단계에서 구체화한다.

## 2. 현재 합의된 시스템
### 진행과 전투
- 적이 없으면 **오른쪽 자동 전진**, 적과 마주치면 **정지 후 자동 기본 공격**, 처치하면 재전진. [확정]
- 플레이어가 **액티브 스킬을 직접 발동**한다. [확정]
- 자동 스킬 발동은 **업그레이드 또는 수집품을 통한 해금**을 검토한다. 해금 방식과 자동 우선순위는 미정. [방향 합의]
- 처치한 몬스터로부터 골드를 획득. 길 위 코인 줍기/점프 기반 코인 수집, 시간 경과형 퀘스트 수익 시스템은 제외. [확정]
- **사망 후퇴 방식 [방향 확정]:** 사망으로 탐험을 종료/강제 환생시키지 않고, 사망 거리 d에 따라 **로그 함수형**으로 계산한 만큼 뒤로 후퇴해 재도전한다. 가까운 초반에는 약 10% 후퇴와 유사하고 먼 거리에서는 후퇴량이 완만하게 증가하는 형태. 시험식은 `R(d)=100×ln(1+d/1000)`(m), 부활 위치는 `max(0,d−R(d))`. **계수 100·1000은 테스트 값이지 확정 수치가 아님.** 사망 거리는 별도로 유지하는 최고 기록과 혼동하지 않는다. 부활 시 체력 및 보스 HP 규칙은 아래 별도 확정 사항을 따른다. 재진입 대기시간과 실제 계수는 미정이며, 별도의 사망 후퇴용 체크포인트는 도입하지 않는다. [방향 합의/공식 계수 미정]
- **사망 후 부활·보스 재도전 [확정]:** 사망 후 로그형 후퇴 거리에 도착하여 **최대 체력까지 회복**한다. 현재 보유 골드와 해당 탐험의 골드 강화 레벨은 **그대로 유지**한다. 후퇴해 다시 지나가는 구간의 일반 몬스터는 재등장하며 **반복 처치 골드를 다시 얻는다**. 보스는 다시 도전할 때 **체력을 전부 회복/초기화**하며, 사망은 **강제 환생으로 연결하지 않는다**. 미처치 보스는 원래 위치에서 재등장하고, 별도 체크포인트는 없다. 부활 지연 및 상태이상·스킬 쿨다운 처리는 추후 상세 설계.
- **세로 기본·가로 확장 시야 [방향 확정]:** 모바일 **세로를 기본 플레이/우선 제작 레이아웃**으로 하고, 가로도 지원한다. 세로는 환생용병단식 전투+강화 정보 분할 분위기, 가로는 임모탈 키우기식 넓은 전장과 측면 HUD 분위기를 참고하되 UI·아트 자체를 복제하지 않는다. **가로에서는 실제로 더 넓은 좌우 월드가 보이도록** 한다(단순 확대/비율만 변환하지 않음). 두 방향은 같은 월드 좌표·진행 상태·보스 위치·스폰/공격 판정을 공유하며 화면 회전 시 플레이 상태를 초기화하지 않는다. 정확한 카메라 FOV·HUD·노치/터치 영역·회전 UX/화면비는 6단계에서 설계하고 실기기 확인한다.
- **거리별 고정 보스 관문 [방향 확정]:** 보스는 각자 지정된 거리/월드 좌표에 배치하며, **일정한 거리 간격을 강제하지 않는다**. 아직 처치하지 않은 보스 위치에 도착하면 전투하며, 패배·사망 후 로그형으로 후퇴했다가 다시 같은 위치로 오면 **보스가 최대 HP 상태로 재등장**한다. **해당 탐험에서 이미 처치한 보스의 위치**는 재통과 시 해당 지역의 **일반 몬스터가 대신 등장**한다(반복 처치 골드 획득 가능). 이미 격파한 보스를 자동 재전투시키거나 별도의 반복 보스 전투 기능을 추가하지 않는다. 일반 환생 시 해당 탐험의 보스 처치 상태는 초기화한다. 선택한 시작 거리 이전의 보스는 출발 시 자동 처치·보상 지급 없이 건너뛰지만, 사망 후퇴로 실제 그 위치까지 내려갔다 재전진하면 미처치 보스와 정상 전투할 수 있다. 정확한 보스 위치·드롭 상세·패턴은 추후 정한다.
- **일반 환생 후 보스 처치 상태 [확정]:** 일반 환생은 새로운 탐험이므로 **회차별 보스 처치 상태를 초기화**하고 실제로 해당 보스 거리까지 전진하면 다시 전투한다. 계정 최고 기록·최초 처치 이력·영구 도감은 별도 영구 기록으로 보존한다. 일반 환생에서 선택한 시작 거리 이전의 보스는 **출발 시 자동 처치·보상 없이 건너뛴다**. 단, 사망 후퇴로 시작 거리 `S`보다 뒤에 도달해 그 보스 지점을 실제 재통과하면 **회차 내 미처치 보스가 정상 등장**하고 처치 시 일반 보스 보상도 획득할 수 있다. 이미 그 회차에서 처치한 보스라면 기존처럼 일반 몬스터로 대체된다. 일반 몬스터의 골드 반복 파밍에도 별도 제한을 두지 않는다. 시작 골드·난이도는 별도 검증한다.
- **별도 체크포인트 없음 [확정]:** 사망 후 로그형 후퇴 위치를 사용하므로 **사망·부활용 체크포인트 시스템은 도입하지 않는다**. 보스 고정 좌표, 계정 최고 거리 기록, 일반 저장/세이브 데이터는 체크포인트와 별개다. 후퇴 후 재도전 실제 소요 시간은 플레이테스트에서 확인한다. 시작 거리보다 뒤로 후퇴해도 별도 위치 제한을 두지 않는다.
- **진행 정체 완화 [핵심 설계 원칙]:** 보스에서 막히는 경험은 허용하지만 반복해도 성장 체감 없이 지나치게 오래 막히는 진행은 피한다. 골드 파밍/강화/유물 보상/자발적 환생 등 설계가 완료된 성장 수단으로 탈출할 길을 제공하고, 강제 과금·드롭 강제·사망 파밍 금지로 해결하지 않는다. **현재는 보스 전용 강제 후퇴/타임아웃/탈출 조작을 추가하지 않는다.** 양쪽이 죽지 않고 교착하는 사례가 프로토타입에서 확인되는 경우에 한해 조정한다. 실제 적정 정체 시간·재도전 횟수·보상과 성장 폭은 플레이 데이터로 검증한다.
- 후퇴/재도전 구간 몬스터 반복 처치로 골드를 버는 행동은 **허용**한다. 비효율 가능성을 이유로 강제 제한·반복 사망 페널티를 임의 도입하지 않는다. [확정]
- 원작의 별도 '100배 공격' 판정은 도입하지 않는다. [확정]

### 캐릭터 능력치
- 기본 스탯 10종 [현재 합의된 명단]: **공격력, 최대 체력, 방어력, 체력 재생, 공격속도, 치명타 확률, 치명타 피해, 이동속도, 스킬 피해, 골드 획득량**.
- 넉백·공격 사거리는 **일반 강화 스탯**에서 제외. 스킬 쿨타임 감소는 **골드 강화 스탯에서 제외**하며 유물/특수 강화 등의 효과 가능성은 열어둔다.
- 각 능력치의 기본값, 수식, 강화당 증가량, 개별 강화 수단, 상한, 골드 비용은 아직 정하지 않는다.
- 최종 스탯은 탐험 중 골드 강화와 영구 수집품 효과 등 여러 경로에서 **함께 증폭**할 수 있어야 한다. 어떤 항을 합하고 곱할지 실제 연산식은 미정.

### 다단계 치명타
- 치확이 100%를 넘어도 버리지 않고 상위 치명타 단계로 연계. 다음 단계에 진입하는 초과 확률은 **10:1 환산**하는 방향. 단계 수/정확한 일반화 계산식은 후속 검증. [설계 초안]
- 모든 단계가 **동일한 치명타 피해 배율 D**를 공유하며, n단계 발동 시 **D^n**으로 피해를 확장한다는 구상. D와 n의 정의, 스킬 적용, 각종 배율 처리 순서 미정. [설계 초안]
- 1단계 초과분을 고스란히 다음 단계 확정 확률로 사용하는 1:1 승급 방식은 지양.

### 보상·수집
- 가칭 '유물'의 **희귀도를 별(★)로 시각화**하는 방향 [합의]. 별 개수, 색상, 명칭, 희귀도 단계 수 미정.
- **보상 출처/지역별 획득 테이블**, **보상 종류/품질**, **수집품 희귀도**를 별도의 축으로 취급 [방향 합의].
- **보스 격파 → 유물 상자 획득 [핵심 획득처 확정]:** 고정 거리 보스의 처치 보상으로 유물 상자를 받는 구조를 핵심으로 둔다. 보스·지역에 따른 상자 종류/등급·유물 풀이 달라질 수 있다. 보스별 상자 지급 확정/확률 여부, 개수, 확률, 개봉 시점은 아직 미정. 특수 몬스터·이벤트 보스·특정 조건 등 **추가 획득처는 후보**이며, 보스 처치만을 유일한 획득처로 단정하지 않는다.
- 희귀 수집, 수집 도감, 중복 획득 누적 강화, 대량 개봉/한꺼번에 보상 확인이 중요 [확정된 선호].
- **상자 획득·개봉 구조 [방향 합의]:** 원작처럼 보스 등의 보상으로 상자를 받아 **보관·누적**하고 플레이어가 원할 때 **개별 또는 일괄 개봉**해 유물을 확인하는 구조를 지향한다. 수집품은 중복 누적/영구 강화와 연결한다. 상자 종류·희귀도·드롭 확률·수량·결과 연출 및 자동 개봉의 존재 여부는 상세 미정. **'상자'·'유물'은 현재 임시 명칭이며, 세계관이 정해진 뒤 유지/변경을 선택한다.**
- 유물로 전투 스탯을 증폭하고 자동 스킬 등 특수 기능을 부여하는 구상. [방향 합의]

### 성장·반복 진행
- **골드 강화(탐험 내 성장)**와 **수집품 강화(영구 성장)**는 역할을 분리. [확정]
- **일반 환생 [초기화 범위 확정]:** 현재 거리(새 출발 위치 선택), 해당 회차 보스 처치 상태, 보유 골드·골드 강화 레벨 초기화. 유물·미개봉 상자·보석·환생 재화·영구 강화·계정 최고 거리·도감 기록 유지. 아직 설계되지 않은 탐험 내 시스템은 도입 시 해당 초기화 범위를 개별 결정한다. **특수 환생은 모든 기존 진행·성장 상태를 유지**한다.
- **환생 전용 재화 [도입 확정]:** 일반 환생의 거리 기반 환생 재화 지급 시스템은 확정이다. 재화의 명칭·사용처·구체 공급량과 이를 소모하는 추가 영구 강화의 구성은 4단계 성장·경제 설계에서 결정한다.
- 골드 강화 비용이 점차 상승할 것이라는 방향만 있음. **비용 수치·공식은 미정**.
- **환생 재화 보상 [방향 확정]:** 도달 거리가 멀수록 보상이 **완만하게 가속 증가**하는 성장 곡선을 채택한다. 지수/기하급수적 급증은 전제하지 않는다. **계산 기준은 회차 최고 도달 거리 `M`과 선택된 시작 거리 `S`의 누적 함수 차액 `F(M)−F(S)`로 확정**했다. 정확한 함수·기울기·구간 보정은 미정이며 단거리 반복 환생과 장거리 돌파의 시간당 효율은 4단계에서 검증한다.
- **일반 환생 시작 거리 [확정 원칙]:** 기본은 0m에서 재출발하며, 플레이어가 시작 위치를 선택한다. 선택 거리는 **계정 최고 도달 거리 및 영구 해금된 시작 거리 범위 이내**여야 한다. 정확한 해금 수단·단위·비용·추천 거리 등은 추후 결정한다. 건너뛴 보스에 대해 출발 시 자동 보상은 없지만, 실제로 뒤로 후퇴해 그 위치를 다시 통과하면 미처치 보스와 전투·보상 획득이 가능하다. 사망 후퇴로 시작 거리보다 뒤로 이동하는 것은 제한하지 않고 일반 몬스터 골드 파밍도 허용한다. '진행도 보존 환생'과는 별개다.
- **환생 직후 부스터 [방향 합의]:** 반복 구간을 빠르게 통과하기 위한 일시적인 부스트 도입을 검토한다. 공격·이동·골드 보너스 등 세부 효과, 시간, 중첩 규칙은 미정.
- **환생 후 시작 거리 선택 [확정 원칙]:** 일반 환생 후 플레이어가 재출발 위치 `S`를 스스로 고른다(기본 0m). **`S`는 계정 최고 도달 거리와 영구 해금 범위를 모두 넘을 수 없다.** 구체적인 영구 해금 방법·해금 상한 증가량·비용, 추천 거리·기존 선택 기억·선택 단위는 미정이다. 보석 소비형 진행도 보존 환생과는 다른 시스템이다.
- **일반 환생 기본 거리 [확정]:** 월드 기준 **100m에 한 번이라도 도달하면 일반 환생 기능을 해금**한다. 이후 환생 실행 시 **해당 탐험의 월드 최고 도달 거리 `M`이 100m 이상이면** 환생 가능하다. 시작 거리 `S>=100m`인 탐험에서는 출발 즉시 보상 없이도 일반 환생을 선택할 수 있다. 첫 100m까지의 전투 난이도와 템포는 프로토타입에서 검증한다.
- **환생 타이밍 [확정 원칙]:** 일반 환생 실행 조건은 **월드 최고 도달 거리 `M>=100m`**로, 시작 거리 대비 실제 전진량과 구별한다. 시작 위치가 400m인 경우 400→450m에서 막히더라도 **환생은 가능하나 해당 탐험 전진량이 100m 미만이므로 거리 기반 환생 재화는 0**이다. 100m 미만 전진에서도 환생 자체는 막지 않는다. UI는 실행 가능 여부와 보상 수령 조건·예상 보상을 분리해 표시한다. 특수 환생은 기존의 보석 소비·연속 비용 증가 규칙을 유지한다.
- **일반 환생 재화 지급 조건·보상 [확정 원칙/함수 수치 미정]:** 일반 환생 **실행**은 월드 최고 거리 `M>=100m`이면 가능하지만, **거리 기반 환생 재화**는 회차 시작 거리 `S`보다 이번 회차 최고 실제 도달 거리 `M`이 **100m 이상 높아야(`M−S>=100m`) 지급**한다. `M−S<100m`에서는 환생할 수 있어도 해당 재화는 **0개**다. 지급 조건 충족 시 기본 보상은 **`max(0,F(M)−F(S))`**이며, `F(d)`는 월드 절대 거리 `d`에 대한 완만하게 가속하는 누적 보상 함수다. 따라서 400→500m 구간 자체의 보상은 **0m 출발로 500m까지 진행한 경우에 포함되는 400→500m 부분 보상과 정확히 같다**. 0→500m는 0~500m 전체 구간 보상을 추가로 받으며, 400→500m 보상은 0→100m보다 크도록 설계한다. 사망 후퇴로 같은 거리를 재통과해도 `M`은 중복 증가하지 않는다. 함수 계수·정수 반올림·고거리 짧은 회차 효율 및 특수 환생 보상과의 중복은 4단계 검증 사항이다. **환생 재화가 0이어도 일반 환생은 허용**하므로 고거리 시작 후 초기 보스에서 막혔을 때 재시작할 수 있다. 보석 소비형 특수 환생의 연속 사용·비초기화 규칙은 변경하지 않는다.
- **마일스톤 [검토 후보]:** 계정 최고 도달 거리와 누적 환생 횟수를 별도 영구 기록으로 두고, 달성 보상·칭호·성장/편의 해금 등을 검토한다. 개별 보상은 원칙적으로 최초 달성 1회, 횟수 목표가 초단기 환생 남발을 강요하지 않도록 설계한다. 구간/수량/보상은 미정.
- **특수 환생 연속 사용 [확정 — B안]:** 특수 환생을 연속 사용하면 **사용할수록 필요한 보석 비용이 증가**한다. 연속 사용 자체는 허용하며, 일반 환생 1회당 고정 사용 횟수 제한을 기본 규칙으로 두지 않는다. 정확한 최초 비용·증분·증가 함수·일반 환생 후 비용 증가 초기화 여부·장기 이용 상한은 경제 검증 후 결정한다. 모든 진행 상태가 유지된다는 특수 환생 본래의 규칙은 변경하지 않는다.
- **특수 환생 / 진행도 보존 환생(가칭) [확정]:** **보석을 소비해 일반 환생 보상을 얻되, 진행 상태를 전혀 초기화하지 않는다.** 현재 거리, 보유 골드, 골드 강화, 기타 탐험 상태/성장 효과와 영구 수집품 등 기존 상태는 그대로 유지한다(지급되는 환생 재화 증가와 보석 비용 지불만 반영). 일반 환생 이후 위치를 정하는 기능과 별개다. 보석 소비량, 보상 계산식, 기존 거리에서 반복 사용 가능 여부 및 사용 조건, 광고 1.5배와의 중첩은 **미정**이다. 과금 연계는 검토하되 보석을 현금 결제로만 획득한다고 단정하지 않는다.
- **환생 보상형 광고 [방향 합의]:** 환생 시 광고를 **선택적으로** 시청하면 환생 재화 총 획득량 **1.5배**를 제공하는 보상안을 채택 방향으로 기록한다. 광고 미시청 시 기본 환생 보상은 그대로 지급한다. 1.5배의 적용 순서, 보정/중첩, 광고 실패 처리, 횟수 제한 등은 미정.
- **광고 부스트 [방향 합의]:** 환생용병단 등에서 참고한 선택형 광고 보너스를 별도로 마련한다. 적용 효과(공격·이동·골드·스킬 등), 지속시간, 상한, 자동/유료 광고 제거, 광고 없이 플레이 가능성 등은 추후 설계한다. **광고 부스트와 환생 직후 부스터가 같은 효과인지 별도 효과인지도 미정**.
- **환생 초기화 범위 [확정 원칙]:** **일반 환생은 보유 골드·골드 강화·회차 보스 처치 상태 및 기존 위치를 초기화**하고 선택된 시작 거리에서 새 탐험을 시작한다. **유물·미개봉 상자·보석·환생 재화·영구 강화·계정 최고 거리·도감 기록은 유지**한다. 앞으로 추가될 시스템의 일시/영구 구분은 해당 시스템 설계 시 결정한다. **특수 환생은 기존 진행·성장 상태를 초기화하지 않는다**(보석 소비·환생 보상 수령만 반영).
- **보상 재추첨 광고 [검토 후보]:** 수집품/상자 결과의 재추첨 기회를 선택형 보상 광고로 더한다. 기존 재추첨 능력·유물 효과와 연계 가능하지만, '광고로 기본 횟수 2배'와 '광고 시 추가 1회' 중 구체적 규칙은 미정. 오클릭을 막기 위해 광고 보상 버튼을 일반 확인/수령 버튼과 분리하고, 명확한 확인 절차를 둔다. 광고 재추첨으로 기존 결과를 잃는 조건은 상세 설계 전에 임의 확정하지 않는다.
- **골드 획득 증가 광고 [검토 후보]:** 광고를 선택해 일정 기간 몬스터 골드 수익을 높이는 방식. 배율·지속시간·재사용 규칙·무료 플레이 영향은 미정.
- **광고 제거 상품 [검토 후보]:** 구매자에게 시간제 광고 버프를 상시 유지하는 모델을 검토. 이 경우 '버프 지속시간 무제한'과 '횟수 제한 보상 무한 수령'은 명확히 구분하고, 상자 재추첨을 무제한 허용하는 것으로 해석하지 않는다. 광고 대체 수령 정책·과금 가격·서버 검증은 운영 기획 단계에서 결정.
- **진행 월드 [유력 방향]:** 모드/지역 선택형으로 끊기보다 먼 거리에 따라 새 지역이 자연스럽게 이어지는 연속 전진 구조를 선호한다. 경계·해금 조건·특수 던전의 분리 여부는 미정.

### 오프라인 AFK 수익·초기 튜토리얼
- **오프라인 AFK 수익 [기본 시간·광고 배율 확정]:** 앱 종료/비활성 시간 동안 **가상 몬스터 자동 사냥을 통한 골드 수익**을 정산한다. 초기 **누적 가능 시간 상한은 1시간**, 이를 **영구 업그레이드 등으로 연장 가능**하게 한다. 최대 확장 시간·단계·비용은 4단계에서 결정한다. 복귀 시 **기본 오프라인 골드는 광고 없이 수령**하며, **선택형 광고를 시청하면 해당 정산 골드를 2배**로 지급한다(환생 재화 광고 ×1.5와 별개). 광고 실패/미시청 시 기본 보상은 그대로 받는다. 온라인 동등 골드 획득 대비 효율은 임시 후보 약 70%이나 아직 확정하지 않는다. 오프라인 거리 전진/보스 격파/유물 상자 획득/환생 보상 자동 수령은 기본안에서 제외한다. 정산 기준·버프 반영·기기 시간 조작·중복 수령 방지·환생과 정산 순서는 이후 검증한다.
- **초기 게임 방법 안내 [방향 확정]:** 처음 접속한 플레이어에게 게임의 최소 필수 조작을 **짧은 반강제 안내**로 학습시키고, 이후에는 상황별 선택적 안내만 보여준다. **자동 전진·자동 공격 관찰 → 몬스터 골드로 첫 강화 → 수동 스킬 사용 → 첫 상자 개봉** 순서가 기본 제안이며, **환생은 최초 해금 시 간단한 별도 안내**로 처리한다. 긴 대사/연출, 전체 플레이를 중단시키는 반복 튜토리얼, 스토리 강제 노출은 제외한다. 실제 필수 단계 수/스킵 정책/시간은 플레이테스트에서 정한다. 두 언어 번역 키를 사용한다.

### 숫자와 표시
- 큰 수 표기는 **K, M, B, T 이후의 확장 단위**를 기본 방향으로 삼고, 설정에서 `1.23e150` 같은 **과학적/지수 표기 전환**을 제공. [합의]
- 원작의 A/B/C → AA/AB 형태는 참고할 수 있지만, 현재 선택한 표기 규칙 자체는 별도.
- 내부 거대 수 연산 자료형/단위 최대 범위/표시 반올림 정책은 기술 설계 시 결정.

## 3. 명시적으로 제외한 것
- 길에 배치된 코인 수집 및 점프 중심 러너 요소
- 시간당/주기별 자동 퀘스트 수입 강화
- 원작의 독립적인 100배 공격
- 넉백·사거리를 일반 골드 강화 스탯으로 도입
- 스킬 재사용 감소를 일반 골드 강화 스탯으로 도입
- 반복 사망/후퇴 자체를 벌주는 금전 제재, 반복 파밍 횟수 제한 (추가 승인 없이는 도입 금지)

## 4. 미결정 쟁점 (임의 확정 금지)
1. 일반 환생 후 미수령 오프라인 골드 정산 순서, 환생 보상 함수 수치, 특수 환생 경제 조건 (후속 단계)
2. 보스와 일반 적의 세부 배치, 부활 지연 및 후퇴 경계 처리
3. 위 10종 중 정확히 무엇을 골드로 강화할지, 기타 강화 시스템 분류
4. 일반 공격/방어/재생/속도/골드/스킬/다단계 치명타의 수학적 계산식
5. 지역 및 이벤트 수집품 풀, 등급 수·별 개수, 개봉 대상물과 중복 최대치
6. 게임명, 세계관, 세로/가로 화면비, 시각 스타일, 오디오, UX·UI
7. 저장/플레이 모드/서버 필요성, 과금 등 운영 범위

## 5. 기획 진행 원칙
- **기획 순서 고정 (우선순위):** ① 콘셉트·핵심 재미 → ② 핵심 플레이 루프 → ③ 전투·스탯 → ④ 성장·경제·수집 → ⑤ 세계·콘텐츠 → ⑥ UI·그래픽·UX → ⑦ 플레이 가능 프로토타입 → ⑧ 밸런스 검증·본격 제작.
- 순서는 **의사결정의 의존 관계**를 뜻하며, 단계별 실제 테스트나 프로토타입 검증은 앞당길 수 있다. 뒤 단계의 이야기를 했더라도 앞 단계 미정 항목부터 정합성을 맞춘다.
- **현재 위치: ② 핵심 플레이 루프의 정책 수준 합의 완료 → ③ 전투·스탯 설계 진입.** ①은 핵심 방향 합의(상세 이름·비주얼은 후속 단계), ④는 선행 아이디어만 기록된 상태. 수식 계수·가격·드롭 등은 예정된 후속 단계에서 검증한다.
- 새로운 기획을 시작할 때 원작(환생용병단)을 최우선 조사하되, 원작 사실 / 팬 위키 추정 / 우리 확정 / 우리 미정 / 개인 의견을 구분한다.
- 구체 비용·성장 곡선·UI 배치를 가정으로 확정하지 않는다. 단계별 완료 조건은 [ROADMAP](ROADMAP.md)에 따른다.
