# 시스템 설계 노트 — 확정 규칙과 가설 구분

이 문서는 [DESIGN_BIBLE](DESIGN_BIBLE.md)을 확장한다. 상충 시 Design Bible을 먼저 정리한다. 숫자 표·밸런스·전투 식은 **제안 단계**이지 실제 게임에 반영된 값이 아니다.

## A. 기본 이동과 전투
1. 캐릭터는 적이 없으면 자동으로 앞으로 이동한다.
2. 적을 만나면 정지해 자동 기본 공격을 한다.
3. 플레이어는 액티브 스킬을 수동으로 사용할 수 있다.
4. 적 처치 시 골드를 받고, 적을 제거한 뒤 다시 이동한다.
5. 자동 스킬 해금은 가능하되 해금 조건·스킬별 정책은 미정이다.

보스 등장 간격, 사정거리 판정, 다수의 적에게 포위됐을 때의 행동, 적 공격 AI, 보스 패턴, 전투 속도는 미정.

## B. 사망·후퇴
- **의도:** 군단형 게임처럼 동료가 대신 싸워주지 않으므로, 개인 캐릭터 사망 시 손실을 원작 지휘관 사망보다 가볍게.
- **방향:** 사망 후 일정 거리 후퇴해 회복/재도전. 체크포인트 기반인지 거리 기반인지 미정.
- **중요:** 후퇴 구간에서 몬스터를 다시 잡아 골드를 버는 것은 악용으로 취급하지 않는다. 임의 제한을 넣지 않는다.
- 부활 대기시간, 체력 회복량, 보스 체력 리셋 여부, 골드/탐험 강화 유지 여부 등은 상세 규칙 미정.

## C. 기본 스탯 후보 (현재 10종 합의)
| 스탯 | 주요 의미 | 연산식·골드 강화 여부 |
|---|---|---|
| 공격력 | 기본 공격 피해 | 세부 미정 |
| 최대 체력 | 생존력 | 세부 미정 |
| 방어력 | 피해 경감 | 세부 미정 |
| 체력 재생 | 시간에 따른 체력 회복 | 세부 미정 |
| 공격속도 | 기본 공격 빈도 | 세부 미정 |
| 치명타 확률 | 다단계 치명타 판정 | 세부 미정 |
| 치명타 피해 | 공통 치명타 피해 배율 | 세부 미정 |
| 이동속도 | 전진 속도 | 세부 미정 |
| 스킬 피해 | 액티브 스킬 피해 증가 | 세부 미정 |
| 골드 획득량 | 적 처치 골드 증가 | 세부 미정 |

- **일반 골드 강화 제외:** 넉백, 공격 사거리, 스킬 재사용 대기시간 감소.
- 단, 쿨다운 감소 효과를 유물/특수 강화 등 다른 곳에서 얻을 가능성은 남겨둔다.
- 위 표는 '스탯의 존재와 역할'에 대한 합의이며 **모든 스탯을 골드 업그레이드로 제공한다는 확정이 아니다**.

## D. 다단계 치명타 — 수학적 시안
- 1단계는 치확 100%에서 확정.
- 초과한 확률이 상위 단계로 넘어갈 때 단계마다 **10:1로 축소**하는 아이디어.
- 예시로 총 치확이 250%면 1단계 확정, 2단계 약 15%의 발동이라는 기존 대화 예시가 있다. 이 값은 **검증되지 않은 시안**이며 단계 경계의 일반식을 확정해야 한다.
- 모든 단계의 치명타 피해 계수는 공통 D, n단계 피해 계수는 `D^n` (D는 예: 200%라면 2.0)이라는 방향.
- 표본 확률 검사·상위 단계 중첩/순차 판정·최대 수치·오버플로·스킬 적용·평균 DPS는 후속 검증.
- **원작의 별도 100배 공격은 제외.**

## E. 성장과 유물의 관계
- 탐험 내 골드 업그레이드는 즉시 성장, 유물/수집품은 반복 도전에도 유지되는 장기 성장.
- 같은 공격력에 여러 출처의 보너스가 겹칠 수 있음. 예시 `(기본 공격력 + 탐험 강화) × (1 + 유물 보너스)`는 **개념 설명**일 뿐 최종 계산 공식은 아니다.
- 유물로 스탯(공격력·치확·치피·체력·스킬 피해·골드 획득량 등)을 증폭하고, 일부 유물은 자동 스킬 같은 특수 기능에 관여 가능.
- 반복 파밍이 장기적으로 느리다는 점은 **플레이 의도**, 실제 골드 비용 성장식·아이템 파밍 속도가 정해진 후 수치로 확인.
- 환생 조건·영구 성장 재화·탐험 강화 초기화 범위는 아직 상세 확정되지 않았다.
- **거리 비례 환생 보상 [방향 확정]:** 도달 거리가 늘수록 보상이 완만하게 가속 증가하도록 설계한다. 지수적 증가나 단순 정비례로 확정하지 않는다. 실제 함수·수치는 탐험 시간과 파밍 효율을 검증한 후 결정한다. 현재 위치와 탐험 최고 거리 중 보상 기준은 아직 미정.
- **일반 환생의 시작 거리:** 기본은 0m. 플레이어가 재시작 위치를 조절하는 기능을 구상하지만, 영구 강화·해금 수단·단위·상한·건너뛴 구간의 보스/보상 처리는 미정. 진행도 보존 환생과 구분한다.
- **환생 직후 부스터 [방향 합의]:** 재출발 후 짧은 구간의 성장/전투/이동 가속 효과를 고려한다. 종류·기간·획득 방법은 미정.
- **시작 거리 사용자 선택 [방향 합의]:** 일반 환생 시 플레이어가 다음 시작 위치를 직접 정한다. 최대 허용 거리와 그 해금 방식은 아직 정하지 않았다. '권장 시작 거리'는 전투 기록 기반 안내 후보로 강제하지 않는다.
- **시작 골드 영구 업그레이드 [도입 후보]:** 일반 환생 후 출발 지점에서 기본 전투가 가능하도록 시작 골드를 지원하는 별도의 성장 후보. 구매 재화, 증가 곡선, 자동 강화 여부는 미정. 진행도 보존 환생의 직접적인 기능으로 가정하지 않는다.
- **첫 환생 개방 100m [제안]:** 100m는 후보 수치로만 보존. 첫 환생까지 걸리는 실제 플레이 시간과 최초 보상 체험을 보고 조정.
- **자유 환생 [권장 방향]:** 최초 해금 후 플레이어가 현재 탐험을 언제 종료할지 선택하게 한다. 보상을 사전에 표시하고 확인 절차를 둔다. 추천 환생 타이밍은 안내만 제공하며 자동/강제 귀환은 현재 확정하지 않는다.
- **특수 환생의 보석-재화 전환 검토:** 동일 거리에서 반복 사용을 허용하면 사실상 보석을 환생 재화로 교환하는 기능이다. 이를 의도적으로 허용할지, 새 전진 성과만 환생 보상을 지급할지, 비용/보상 효율을 어떻게 정할지 **경제 설계 때 검토한다**. 현재 횟수 제한이나 거리 갱신 조건을 임의로 부과하지 않는다. 일반 환생의 거리 건너뛰기와 보스/도감 보상 처리는 별도 검토한다.
- **환생 보상 구성 [검토]:** 해당 탐험에서 도달한 거리 기반 영구 재화, 획득/보관된 수집 보상, 최초 기록 달성 보상 등을 분리하는 방향. 기존 '완만한 가속 증가' 곡선은 유지. 환생 재화 사용처/수집 보상 귀속 시점은 확정하지 않는다.
- **마일스톤 [검토 후보]:** (A) 최고 거리 갱신 기준 (B) 누적 환생 횟수 기준. 계정 영구 기록과 1회 달성 보상을 기본 방향으로 하며, 구체 횟수·거리·보상/칭호·경제 영향은 후속 기획.
- **특수 환생(진행도 보존형) [확정]:** 보석을 소비하면 환생 보상이 지급되지만 **현재 거리·보유 골드·골드 강화·기존 전투/탐험 진행 상태 등 모든 성장 상태를 초기화하지 않는다**. 진행 상태 변경은 보석 차감 및 신규 환생 보상 지급뿐이다. 사용 가능 조건·보석 가격·동일 거리에서 반복 구매 가능 여부·보상 계산·광고 보너스와의 중첩 등은 추후 경제 검증. 일반 환생의 출발 거리 선택과 별개다.
- **환생 광고 보상 [추가 결정]:** 환생 완료 시 보상형 광고를 선택해 환생 재화 ×1.5. 기본 환생은 광고 시청과 무관하게 가능해야 한다. 지급 확정/실패/보정 중첩 시점은 미정.
- **광고 부스트 [추가 결정]:** 선택형 보상 광고로 일시 강화·편의 효과를 제공한다. 원작처럼 광고를 활용하되 실제 보상 종류, 지속시간, 관문, 매회 사용 제한은 조사 후 결정. 환생 직후 부스터와의 중복/분리 관계는 미정.
- **참고:** 보석 관련 진행도 보존 환생과 광고 시 환생 재화 ×1.5는 별개 효과다. 둘의 중첩 가능성과 보상 수령 시점은 추후 설계한다.
- **연속 지역 [유력 방향]:** 단일 전진 동선에서 거리 증가에 따라 지역이 바뀌는 설계를 우선 검토한다. 고유 던전/이벤트와의 관계는 미정.
- 참고 비교: Tap Titans 2의 Advanced Start는 6.0 이후 보유 마일스톤 기반 **재시작 위치 상승**(공식 도움말: https://gamehive.helpshift.com/hc/en/3-tap-titans-2/faq/77-how-does-advanced-start-work/?p=web)이다. **우리의 진행도 보존 환생과 다른 개념**이므로 동일한 선행 사례로 취급하지 않는다.

## E-1. 초기화와 광고 관련 기획 메모 (아직 운영 설계 전)
- **환생 시 초기화 대상:** 특수 환생은 **초기화 없음 확정**. 일반 환생은 현재 보유 골드·골드 업그레이드 초기화가 유력하고 유물/보석/영구 성장 유지가 방향이다. 아직 없는 경제·성장 시스템의 **일반 환생 초기화**는 각 시스템 설계 때 별도로 확정한다.
- **수집품 재추첨 광고 [제안]:** 상자/수집품 개봉 결과에서 의도적으로 선택한 광고로 재추첨 기회를 얻는다. 일반 보상 수령 동작과 분리하고 재확인 절차 및 현재 결과 보존/변경 정책을 정의한다. 기존 능력으로 얻는 재추첨 기회와 광고 보상을 연계하되 2배 기회/추가 1회/횟수 상한은 미정.
- **골드 획득 버프 광고 [제안]:** 광고를 선택적으로 보면 특정 시간 동안 몬스터 골드 보상이 증가. 수치·지속시간·갱신/중첩은 미정.
- **광고 제거 패키지와 상시 버프 [제안]:** 시간제 광고 버프를 패키지 보유 시 상시 유지하는 사례를 검토한다. 유효시간 무한화와 소모성 보상·재추첨 횟수 무한화는 다르다. 재추첨이나 보상 횟수 제한까지 제거할지는 따로 기획해야 한다.
- 임모탈 키우기(Immortal Rising)의 광고 건너뛰기·무제한 버프 패키지는 2024년 유저 공략에서 사례가 확인된다. 본 게임의 상용 정책이나 현재 판매 여부와 일치한다고 단정하지 않는다. 참고: https://note.com/shigre_brog/n/n36ffb5af4a56?hl=en
- 광고 시스템은 핵심 플레이 루프보다 뒤 단계의 구상으로 보존만 하고, 현재 단계의 핵심 의사결정을 대신하지 않는다.

## F. 보상·수집 설계 축
1. **보상 출처:** 보스/특수몹/이벤트 보스/달성 조건/지역.
2. **보상 용기 또는 획득 방식:** 상자 등은 미정.
3. **보상의 품질·등급:** 어떤 등급이 등장하는지, 확률 분포.
4. **수집품의 희귀도:** 별(★) 표시, 정확한 등급 개수 미정.
5. **지역별 수집품 목록:** 출처마다 획득 가능한 세트가 다름.
6. **중복 성장:** 반복 획득 가치가 있어야 함.
7. **도감/대량 확인:** 희귀 획득·수집 현황·중복 수집·많이 모아 한 번에 여는 즐거움을 모두 중요하게 취급.

확률 수치, 보상 테이블, 이름, 연출을 원작과 동일하게 복사하지 않는다.

## G. 초고수치와 표시
- UI 기본 단위 K/M/B/T… (확장 단위 규칙 미정), 과학적 표기법 선택 가능.
- 내부 계산은 초고수치를 안전하게 처리할 타입·오차 정책을 검증해 정할 것.
- 표시 단위가 게임 내부 실제 값·확률 연산을 변형하면 안 됨.

## H. 아직 확정할 단계가 아닌 것
스탯 강화 비용, 레벨당 증가량, 10레벨/100레벨 보너스 채택, 치명타 상한, 수집품 개수, 등급별 확률, 보스 간격, 스킬 목록, 대량 개봉 최소치, 환생 배율, UI 레이아웃.
