# Stackfall PC/Web → Mobile 변환 규칙

이 문서는 기존 `q93503128-a11y/Stackfall`을 참고할 때 반드시 적용하는 변환 규칙이다.

## 1. 기본 원칙

모바일판은 포팅이 아니다.

기존 Stackfall에서 가져오는 것은:

- 공격 정체성
- 중첩에 따른 동작 확장
- 전장 제어/집중 사격/공전/드론/연쇄 등 아이디어
- 보스와 이벤트로 전투 리듬을 바꾸는 방식

그대로 가져오지 않는 것은:

- PC 입력
- PC 화면 크기 기준 UI
- PC용 시야와 사거리
- 현재 웹판 밸런스 수치
- 무한 생존 전제의 시간 구조
- 브라우저 로컬 중심 저장 구조

## 2. 입력

### PC 원본

- 키보드 이동
- 마우스 위치 기반 선택적 수동 조준 가능

### 모바일

기본:

- 한 손 드래그 또는 가상 스틱으로 이동
- 공격 자동 조준
- 특수 능력이 필요하면 화면 하단 1~2개 액션 버튼 이내

금지:

- 작은 적을 직접 터치해 지속적으로 타깃 변경
- 화면 여러 곳을 동시에 눌러야 하는 조작
- 마우스 포인터 정밀도를 전제로 한 공격

수동 개입은 `우선 타깃`, `궁극기`, `대시`, `설치 위치`처럼 의미가 큰 순간에만 사용한다.

## 3. 화면 방향과 카메라

초기 기준은 세로 화면 우선으로 연구한다.

카메라 원칙:

- 플레이어 주변 위험이 충분히 보이는 고정/완만한 추적 카메라
- 보스 공격 예고가 화면 밖에서 갑자기 날아오지 않게 함
- 장거리 공격은 PC판처럼 무작정 사거리를 늘리지 않고 카메라 크기에 맞춰 재조정
- 화면 가장자리 스폰은 최소 안전거리와 공격 예고 시간을 둠

## 4. 적 밀도

PC판의 적 수를 동일하게 유지하지 않는다.

모바일에서는 다음 우선순위를 사용한다.

1. 위험한 적을 읽을 수 있는가?
2. 보스/엘리트 패턴이 잡몹에 묻히지 않는가?
3. 플레이어 공격이 무엇을 하고 있는지 보이는가?
4. 기기 성능이 안정적인가?
5. 그 뒤에 적 수를 늘린다.

난이도는 적 수만으로 만들지 않는다.

- 이동속도
- 진형
- 공격 주기
- 방어 특성
- 원거리/근거리 혼합
- 지역 통제
- 엘리트 조합

을 사용한다.

## 5. 투사체와 VFX

- 적 투사체와 플레이어 투사체 색/형태 역할을 명확히 분리
- 적의 치명적 공격은 아군 VFX보다 항상 우선해서 보임
- 화면을 덮는 장식 파티클은 제한
- 고등급 부품의 강함을 단순 파티클 수 증가로만 표현하지 않음
- 투사체 숨김/간소화 옵션을 검토

## 6. 자동 조준

기본 자동 조준 후보 우선순위:

1. 공격 목적에 맞는 유효 표적
2. 사거리
3. 보스/엘리트 우선 옵션
4. 현재 락 유지 여부

웹판의 무기별 정체성을 모바일에서 유지한다.

예:

- 집중 무기: 한 표적에 화력 집중
- 연쇄 무기: 여러 적 사이 전이
- 중력: 적 밀집 지역
- 부메랑: 먼 적을 향해 왕복
- 공전: 조준보다 플레이어 주변 위치가 핵심

## 7. 레벨업 카드 UI

- 전투를 명확히 일시정지하거나 안전한 슬로모션 처리
- 한 화면에서 3개 선택지를 기본으로 연구
- 카드 설명은 한눈에 읽히게 2~4줄 수준
- 내부 계산식은 숨기고 실제 플레이 효과를 설명
- 이미 가진 빌드와 시너지가 있으면 시각적으로 표시

## 8. 스테이지 시간

PC 무한 생존 구조를 메인 진행에서 사용하지 않는다.

모바일 기본:

- 5~15분 내 명확한 종료
- 중간 체크포인트
- 일시중단 후 복귀 지원 검토
- 챕터 보스 전에 장시간 무의미한 대기 구간 금지

한 판이 길어질수록 앱 백그라운드 전환/전화/배터리 문제를 고려해야 한다.

## 9. UI 밀도

메인 전투 HUD 최소 요소:

- 체력/보호막
- 진행 시간 또는 목표
- 경험치/레벨
- 보스 체력
- 필수 능력 버튼

전투 중 다음을 상시 노출하지 않는다.

- 전체 장비 설명
- 세부 스탯 표
- 상점 배너
- 채팅 전체창

## 10. 성능

웹판에서 허용되던 객체 수를 기준으로 삼지 않는다.

필수:

- 적/투사체/VFX 풀링
- 공간 분할 또는 효율적 근접 탐색
- 자동 조준 탐색 빈도 예산화
- 동일 프레임 대량 스폰 제한
- 고비용 이펙트 품질 단계
- 해상도 스케일링 옵션
- 장시간 전투 메모리 누수 검사

## 11. 저장과 네트워크

전투 중 네트워크가 끊겨도 즉시 플레이 불가 상태가 되지 않게 설계한다.

단, 서버 가치가 있는 결과를 클라이언트가 독단적으로 확정하지 않는다.

예:

- 전투 시작 시 세션/시드/입장권 검증
- 전투 종료 시 결과 제출
- 비정상 기록 검증
- 보상은 서버가 확정

## 12. 모바일 UX 금지사항

- 44px 이하 수준의 지나치게 작은 중요 버튼
- 노치/홈 인디케이터 영역 침범
- 뒤로가기 동작 무시
- 긴 로딩 후 아무 피드백 없음
- 전투 중 강제 상점 팝업
- 실수 터치를 유도하는 버튼 겹침
- 광고/구매 버튼을 게임 기본 조작과 혼동되게 배치

## 13. 원본 기능 분류 절차

기존 Stackfall 기능을 가져올 때 각 항목에 다음 중 하나를 붙인다.

- `KEEP DNA` — 정체성 유지
- `MOBILE REDESIGN` — 개념만 유지하고 모바일 재설계
- `META CONVERT` — 영구 성장/부품으로 이동
- `DROP` — 모바일판에서 제거
- `RESEARCH` — 프로토타입 후 결정

이 분류 없이 PC 코드를 그대로 옮기지 않는다.
