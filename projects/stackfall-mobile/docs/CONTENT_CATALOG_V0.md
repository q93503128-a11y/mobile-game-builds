# Stackfall Mobile 콘텐츠 카탈로그 V0

상태: `Phase 0 후보 정본`

목적: 프로토타입/초기 제작에서 무엇을 실제 콘텐츠로 만들지 범위를 제한한다. 숫자를 채우기 위한 유사 스킬/부품 양산을 금지한다.

---

## 1. 전투 공격 능력 후보 12종

### 1. 코어 펄스
- 역할: 기본 자동 추적 단일/소수 표적
- 조작: 완전 자동
- 성장 핵심: 발사 리듬 → 관통/분열 → 고속 집중
- 대표 태그: `집중 / 투사체 / 기본공격`

### 2. 펄스 블레이드
- 역할: 근거리 공전 지속 피해
- 성장 핵심: 칼날 수가 아니라 궤도/반경/회전 형태도 변화
- 대표 태그: `공전 / 근접 / 지속`

### 3. 별빛 캐스터
- 역할: 빠른 집중 연사
- 성장 핵심: 연사 리듬, 짧은 폭발, 연속 적중 보너스
- 대표 태그: `연사 / 집중 / 폭발`

### 4. 중력 우물
- 역할: 적 집속 + 지역 제어
- 성장 핵심: 흡인, 지속시간, 종료 붕괴파
- 대표 태그: `중력 / 설치 / 광역`

### 5. 혜성 창
- 역할: 느리지만 강한 장거리 관통
- 성장 핵심: 관통 수, 적중 후 파편, 직선 폭발
- 대표 태그: `관통 / 직선 / 강타`

### 6. 성좌 프리즘
- 역할: 엘리트/보스 단일 대상 집속광선
- 성장 핵심: 표적 유지 → 과열 단계 → 교차광선
- 대표 태그: `광선 / 집중 / 보스`

### 7. 성운 부메랑
- 역할: 먼 적을 향한 곡선 왕복
- 성장 핵심: 왕복 경로, 잔광, 귀환 피해
- 대표 태그: `왕복 / 곡선 / 지속경로`

### 8. 이온 사슬
- 역할: 잡몹 다중 정리
- 성장 핵심: 연쇄 횟수, 연쇄거리, 상태 전염
- 대표 태그: `연쇄 / 전기 / 다중`

### 9. 초신성 코일
- 역할: 플레이어 주변 압박 해소
- 성장 핵심: 파동 주기, 범위, 적중한 적 수에 따른 재충전
- 대표 태그: `중심파동 / 광역 / 생존`

### 10. 유성 드론
- 역할: 독립 편대 집중사격
- 성장 핵심: 편대 행동, 2연사, 표식 유성
- 대표 태그: `드론 / 자동 / 집중`

### 11. 성간 레일
- 역할: 직선 다수 관통
- 성장 핵심: 평행선, 충전, 맞힌 적 수 보너스
- 대표 태그: `레일 / 관통 / 광선`

### 12. 은하 나선
- 역할: 나선형 탄이 한 표적에 수렴
- 성장 핵심: 나선 폭/회전수/수렴 폭발
- 대표 태그: `나선 / 집중 / 투사체`

## 2. 연구 보류 공격 3종

다음은 정체성은 좋지만 초기 프로토타입에 바로 넣지 않는다.

- `성광 장벽` — 공격 슬롯보다 방어/프레임 계통과 역할이 겹칠 수 있음
- `시간 고리` — 감속이 보스/엘리트 설계와 충돌할 수 있어 제어 규칙 필요
- `반사 성좌` — 적 투사체 콘텐츠 비중이 충분해야 가치가 생김

프로토타입 후 각각 공격/지원/부품 고유효과 중 어디에 둘지 확정한다.

---

## 3. 공격 성장 구조

공격 능력은 기본적으로 `Lv.1~5 + 진화`를 목표로 한다.

- Lv.1: 능력 획득
- Lv.2: 핵심 수치 강화
- Lv.3: 첫 행동 변화
- Lv.4: 수치/주기 강화
- Lv.5: 두 번째 행동 변화 또는 진화 준비
- 진화: 명확한 최종 행동/외형 변화

연속 두 단계 이상 `피해 +N%`만 주는 설계를 금지한다.

## 4. 지원 프로토콜 후보 16종

지원 슬롯 최대 4개.

| 이름 | 역할 |
|---|---|
| 출력 증폭기 | 공격 피해 |
| 가속 회로 | 공격/스킬 주기 |
| 취약점 해석기 | 치명타 확률/조건 |
| 파열 증폭기 | 치명타 피해/강타 |
| 광자 팽창기 | 범위/판정 크기 |
| 광자 가속기 | 투사체/공전 속도 |
| 관통 렌즈 | 관통/직선 계통 |
| 다중 투영기 | 제한적 공격체 추가 |
| 연쇄 과부하 | 연쇄 유지/피해 |
| 연쇄 추진기 | 연쇄 기반 공격주기 |
| 수집 자기장 | 경험치 흡인 |
| 성운 통찰 | 경험치 획득/빠른 성장 |
| 거성 사냥 프로토콜 | 보스/엘리트 특화 |
| 임계 과출력 | 저체력 공격 강화 |
| 자가 복구 프로토콜 | 조건부 회복 |
| 비상 방벽 | 보호막/피격 완화 |

순수 스탯형 프로토콜은 행동 변화형보다 낮은 제작 우선순위를 가진다.

## 5. 진화 조건

특정 영구 S 부품 보유를 전투 스킬 진화의 필수 조건으로 만들지 않는다.

진화는 전투 안에서 달성 가능해야 한다.

V0 규칙:
- 공격 능력 Lv.5
- 관련 태그의 지원 프로토콜 1개 이상 보유
- 다음 레벨업/엘리트 보상에서 진화 후보 활성화

예:
- 중력 우물 Lv.5 + 광자 팽창/가속 계통 → `중력붕괴`
- 유성 드론 Lv.5 + 다중 투영/가속 계통 → `유성 편대`
- 성좌 프리즘 Lv.5 + 취약점/거성 사냥 계통 → `과열 성선`

영구 S 부품은 진화 자체를 잠그는 대신 진화의 추가 효과/시작 단계/변형을 제공한다.

## 6. 일반 영구 부품 후보 — Core

### 펄서 코어
- 범용 출력
- 희귀 이상: 기본 공격 적중 누적 보너스
- 역할: 초반 범용 공격형

### 공명 코어
- 치명타/연속 적중
- 영웅 이상: 일정 연속 적중 후 짧은 출력 상승
- 역할: 연사/프리즘 계통

### 플럭스 코어
- 스킬 회전
- 영웅 이상: 일정 횟수 스킬 발동 후 다음 스킬 가속
- 역할: 스킬 빈도형

## 7. 일반 영구 부품 후보 — Frame

### 바스티온 프레임
- 최대 HP/피해 완화
- 역할: 범용 생존

### 반응장갑 프레임
- 피격 후 짧은 보호막
- 연속 발동 내부 쿨다운 존재
- 역할: 순간 피해 대응

### 경량 프레임
- 이동/공격 보정
- 최대 HP 일부 감소
- 역할: 고위험 기동형

---

## 8. 일반 영구 부품 후보 — Drive

### 벡터 드라이브
- 이동속도
- 일정 시간 같은 방향 이동 시 추가 가속

### 위상 드라이브
- 대시 기능을 채택할 경우 대시 강화
- 대시 미채택 빌드에서는 짧은 피해 회피/급가속으로 재설계

### 자이로 드라이브
- 방향 전환/근거리 회피
- 주변 적이 많을 때 기동 보정

## 9. 일반 영구 부품 후보 — Impactor

### 충각 헤드
- 가까운 적/충돌 계통
- 적을 밀거나 파동 발생

### 절단 엣지
- 근거리/공전 공격 강화
- 펄스 블레이드와 시너지

### 충격 해머
- 느린 강타/넉백/엘리트 압박
- 보스에는 넉백 대신 추가 피해로 변환

## 10. 일반 영구 부품 후보 — Orbiter

### 정찰 오비터
- 소형 자동 보조사격
- 유성 드론과 별개로 약한 기본 보조화력

### 가드 오비터
- 위험 투사체 대응/보호막 보조
- 적탄 비중이 낮은 스테이지에서는 피해감소 계통 보정

### 마그넷 오비터
- 경험치/전리품 흡인
- 전리품 회수 편의 + 수집 빌드 시너지

---

## 11. 일반 영구 부품 후보 — Reactor

### 가속 리액터
- 공격/스킬 주기
- 범용 회전형

### 에코 리액터
- 낮은 확률의 공격 복제
- 같은 프레임 중 무한 연쇄 복제를 금지

### 체인 리액터
- 연쇄/콤보 유지와 임계 효과
- 연쇄 계통 스킬과 시너지

## 12. S 프로토타입 계통

V0에서는 다음 네 계통을 유지한다.

1. `과부하` — 속도/처치/폭주
2. `중력붕괴` — 집속/광역/붕괴
3. `요새` — 보호막/반격/생존
4. `공허` — 이동/위상/잔상

각 계통은 6부품을 가지므로 전체 24개의 S 부품이 될 수 있다.

단, 가챠 풀에 24개를 무차별 혼합해 원하는 부품 확률을 과도하게 희석하지 않는다. `세트 선택/픽업/목표 슬롯` 같은 집중 장치를 별도로 설계한다.

## 13. 첫 Unity 프로토타입용 실제 제작 목록

Phase 1에서는 전체 카탈로그를 만들지 않는다.

실제 구현 우선순위:

### 공격 4종
- 코어 펄스
- 펄스 블레이드
- 중력 우물
- 유성 드론

### 지원 6종
- 출력 증폭기
- 가속 회로
- 취약점 해석기
- 광자 팽창기
- 수집 자기장
- 비상 방벽

### 영구 부품
프로토타입에서는 실제 가챠/인벤토리 없이 데이터 구조만 준비하고 다음 6개를 테스트용으로 사용한다.
- 펄서 코어
- 바스티온 프레임
- 벡터 드라이브
- 절단 엣지
- 정찰 오비터
- 가속 리액터

S 부품은 전투 코어 검증 후 추가한다.

## 14. 콘텐츠 추가 규칙

새 스킬/부품을 추가하기 전에 다음 중 최소 하나가 기존 항목과 달라야 한다.

- 표적 선택
- 궤도
- 공격 시점
- 위치 관계
- 위험/보상 조건
- 상태이상/상호작용
- 세트 역할
- 외형 변형

단순히 `기존 공격 + 피해 20%`인 콘텐츠는 별도 아이템으로 만들지 않는다.
