# Stackfall Mobile 출격 덱/액티브 편성 V0

상태: `v0.1 — LOCKED DIRECTION`

목적: 액티브/지원 능력이 계속 추가되어도 전투 중 3택 RNG가 무너지지 않게 하고, 스테이지 진입 전 빌드 의도를 만들며, 새 능력 해금이 실제 진행 동기로 작동하게 한다.

## 1. 기본 구조

플레이어는 계정 전체 능력을 전부 한 판의 랜덤 풀에 넣지 않는다.

출격 전 두 종류의 후보 덱을 편성한다.

- `액티브 덱`: 최대 8종 후보
- `지원 덱`: 최대 8종 후보

한 판에서 실제 획득 가능한 최대 슬롯:

- 액티브 최대 6종
- 지원 최대 4종

즉, 덱은 `이번 판에 등장할 수 있는 후보군`이고, 전투 슬롯은 `실제로 이번 판에서 완성한 빌드`다.

## 2. 초반 온보딩

Stage 1~19에서는 편성을 강제하지 않는다.

- 해금된 능력 수가 적으므로 자동 추천 덱을 사용
- 신규 해금 능력은 일정 기간 등장 보정
- 사용자는 전투와 레벨업 규칙을 먼저 학습

Stage 20 전후에 `출격 편성`을 해금한다.

해금 시:
- 추천 덱 자동 생성
- 직접 편성 안내 1회
- 이후 스테이지마다 재편성을 강요하지 않음

## 3. 액티브 덱

액티브는 실제 공격 형태를 만드는 능력이다.

예:
- 코어 펄스
- 펄스 블레이드
- 중력 우물
- 별빛 캐스터
- 혜성 창
- 성좌 프리즘
- 성운 부메랑
- 이온 사슬
- 초신성 코일
- 유성 드론
- 성간 레일
- 은하 나선

출시 후 액티브 수는 계속 늘릴 수 있다.

원칙:
- 공격 역할이 겹치는 능력을 숫자만 달리해 양산하지 않음
- 단일, 공전, 설치, 광역, 관통, 연쇄, 드론, 광선 등 동작 정체성을 우선
- 신규 액티브 추가가 기존 전체 RNG를 자동으로 악화시키지 않음

## 4. 지원 덱

지원은 피해/주기/범위/생존/경험치/태그 시너지를 담당한다.

한 판에서 지원 최대 4종을 실제 확보한다.

지원 덱 후보는 최대 8종이므로 유저가 원하는 진화 방향을 어느 정도 계획할 수 있다.

## 5. 전투 중 3택 생성 규칙

레벨업 시 기본적으로 3개 후보를 제시한다.

우선순위:
1. 이미 획득한 액티브/지원의 성장
2. 아직 비어 있는 전투 슬롯에 들어갈 덱 내 신규 능력
3. 진화 조건을 만족한 진화 후보

보정:
- 같은 카드가 지나치게 연속 등장하지 않음
- 장시간 특정 덱 카드가 하나도 안 나오는 상황에 소프트 보정
- 신규 해금 능력은 첫 체험 보정
- 이미 슬롯이 가득 찼으면 신규 능력 카드를 제시하지 않음

## 6. 진화와 덱의 관계

진화는 별도 덱 슬롯을 차지하지 않는다.

예:
- `중력 우물 Lv.5 + 관련 지원` → `중력붕괴`

진화 후에도 액티브 슬롯 1칸으로 취급한다.

영구 S 부품은 진화를 잠그는 조건이 아니라:
- 추가 효과
- 시작 랭크
- 다른 형태의 변형
- 태그 보너스

등을 제공한다.

## 7. 프리셋

기본 프리셋 3개:
- 메인
- 보스
- 아레나

프리셋마다 저장:
- 액티브 덱 8
- 지원 덱 8
- 6부품 장착

예:

`메인`
- 광역/집속/생존 균형

`보스`
- 성좌 프리즘, 혜성 창 등 단일 DPS 비중 증가

`아레나`
- 생존, 순간폭딜, 제어 대응 중심

## 8. 추천 덱

자동 추천을 제공한다.

추천 기준:
- 현재 장착 부품 세트
- 현재 스테이지 적 구성
- 보스/일반/아레나 콘텐츠 유형
- 해금된 능력

`자동 편성`과 `유저 직접 편성`을 모두 지원한다.

자동 편성이 유저 선택을 덮어쓰지 않는다.

## 9. 신규 능력 해금과 연결

스테이지 최초 클리어로 새 능력이 해금되면:

1. 결과 화면에서 신규 카드 크게 표시
2. 신규 능력을 덱에 바로 넣을 수 있는 CTA 제공
3. 자동 추천 프리셋에도 후보로 반영
4. 다음 3판은 등장 보정

그래서 `스테이지 진행 → 새 능력 → 덱 변경 → 새 플레이 체험`이 하나의 루프가 된다.

## 10. 장기 확장

액티브가 30~50종 이상으로 늘어나도 기본 전투 RNG는 액티브 덱 8종 안에서만 동작한다.

추가 가능한 후기 시스템:
- 액티브 숙련도
- 능력별 스킨/외형
- 능력 계열 연구
- 시즌 추천 덱
- 특정 콘텐츠 임시 규칙

단, 액티브 카드 자체를 가챠에서만 얻어야 하는 구조는 초기에는 채택하지 않는다. 메인 진행 해금과 실제 플레이 동기를 먼저 유지한다.

## 11. 과금과의 관계

액티브 해금 자체는 메인 진행의 재미로 둔다.

과금은 다음 쪽에서 강하게 작동한다.
- 영구 기체 부품
- S 프로토타입
- 성장 재료
- 패스
- 프리미엄 재화
- 외형
- 편의/추가 시도

핵심 액티브를 직접 유료 잠금하면 전투 콘텐츠 폭이 과금 여부에 따라 갈라지고 밸런스가 어려워지므로 초기에는 피한다.

## 12. 첫 테스트 범위

첫 테스트에서는 액티브 3종만 실제 구현되어도 된다.

하지만 UI 구조는 최종 확장을 가정해:
- 액티브 덱 8칸
- 지원 덱 8칸
- 전투 슬롯 6+4

구조로 먼저 만든다.
