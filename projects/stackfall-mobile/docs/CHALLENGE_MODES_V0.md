# Stackfall Mobile 도전 콘텐츠 정본 V0

상태: `Phase 0`

목적: 메인 스테이지 외 반복 플레이가 각각 다른 성장 이유를 만들고, 경쟁 콘텐츠가 장비/부품 과금의 사용처가 되게 한다.

## 1. 공통 원칙

- 모든 콘텐츠가 같은 재료만 뿌리지 않는다.
- 입장 제한과 보상 구조는 콘텐츠 목적에 맞게 다르게 설계한다.
- 실패했을 때 모든 재화를 항상 소모하는 구조는 피한다.
- 자동전투/스킵은 충분히 검증된 반복 콘텐츠에서만 단계적으로 연다.
- 경쟁 점수는 서버 검증 대상이다.
- 보상량은 일일 의무감이 과도해지지 않도록 `짧은 일일 + 긴 주간` 구조를 섞는다.

## 2. 일일 던전

### 크레딧 채굴장
- 목적: 슬롯 강화용 크레딧
- 무료: 하루 2회
- 추가: 광고 1회 + 던전 티켓
- 시간: 3~5분
- 난이도: 계정 진행도에 따라 단계 해금

### 정밀부품 회수전
- 목적: 10레벨 단위 승급 재료
- 무료: 하루 2회
- 추가: 티켓
- 보스/엘리트 비중 높음

### 프로토타입 잔해지대
- 목적: 조율 데이터/고등급 분해재료
- 주간 횟수 제한형
- 초기에는 매우 적은 양만 지급해 S 가챠를 대체하지 않게 함

## 3. 보스 격파전

핵심: 제한시간 내 최대 피해량.

- 기본 제한시간: 90초
- 무료 시도: 하루 3회
- 추가 시도: 보스 티켓
- 한 시도 중 죽으면 기록 종료
- 최고 기록과 일일/주간 누적 피해를 모두 저장

랭킹:
- 서버/샤드
- 국가
- 글로벌
- 길드 내

보상:
- 개인 누적 마일스톤: 대부분의 필수 재료
- 순위 보상: 추가 크리스탈, 조율 데이터, 프로필 장식, 한정 외형 재료

상위 1%만 필수 성장 재료를 독점하지 않게 한다.

## 4. 무한 탑

- 1층부터 순차 진행
- 5층마다 엘리트
- 10층마다 보스
- 층당 1~3분
- 이미 클리어한 구간은 시즌/주간 규칙에 따라 빠른 소탕 가능

보상:
- 최초 클리어 보상
- 일정 층 마일스톤
- 시즌 최고층 보상

특정 층에서는 단순 스탯보다 빌드를 요구한다.

예:
- 보호막 적 비중 증가
- 이동 패턴 강제
- 근거리 위험 증가
- 보스 단일 DPS 체크

## 5. 아레나 V0

초기 방식: 비동기 PvP.

플레이어는 `방어 기체 스냅샷`을 서버에 저장하고 상대는 해당 스냅샷을 기반으로 생성된 AI 상대와 싸운다.

### 입장
- 무료 5회/일
- 아레나 티켓으로 추가
- 상대 목록 무료 갱신 횟수 제공
- 추가 갱신에는 소량 크레딧 또는 크리스탈 사용 후보

### 전투 시간
- 목표 60~120초
- 승패가 지나치게 길어지면 후반 가속 규칙 적용

### 티어
- Bronze
- Silver
- Gold
- Platinum
- Diamond
- Master
- Grandmaster

### 점수
- 비슷한 점수대 매칭
- 높은 상대 승리 시 추가 점수
- 낮은 상대 패배 시 더 큰 손실
- 시즌 말 소프트 리셋

### 과금 연결
- 부품/세트/프리셋 차이가 실제 성능에 반영됨
- 단순 전투력 높은 쪽 100% 승리 구조는 금지
- 특정 시즌 규칙으로 메타를 순환할 수 있음

## 6. 길드 보스

- 개인 시도 횟수: 하루 2회
- 길드 전체 누적 피해
- 개인 피해 마일스톤 + 길드 누적 마일스톤
- 주간 보스 교체

보상:
- 길드 코인
- 길드 연구 재료
- 일반 성장재료
- 상위 단계 조율 데이터 소량

개인 고과금 유저 한 명이 길드 전체를 완전히 대체하지 않도록 참여 인원 보너스도 둔다.

## 7. 시즌 이벤트

기본 주기 후보: 14~28일.

형태:
- 이벤트 스테이지
- 이벤트 보스
- 별도 마일스톤
- 이벤트 상점
- 시즌 패스

기본 게임에서 쓰는 기체를 그대로 가져가되 시즌 규칙으로 특정 태그/세트를 강화할 수 있다.

## 8. 스킵/소탕

허용 조건:
- 이미 충분히 높은 등급으로 클리어
- 반복 플레이가 새로운 판단을 거의 요구하지 않음

금지:
- 보스 랭킹 최고기록 자동 산출
- 아레나 결과 자동 생성
- 최초 메인 스테이지 자동 클리어

## 9. 보상 설계 원칙

필수 성장재료는 `참여 마일스톤`에서 대부분 확보 가능하게 한다.

랭킹 상위 보상은:
- 추가 성장 속도
- 크리스탈
- 선택권
- 전용 칭호/프레임/외형

을 중심으로 한다.

상위 유저가 강해질 이유는 확실히 주되, 하위 유저가 필수 시스템 자체를 못 쓰게 만들지는 않는다.

## 10. 사용자 테스트 게이트

실제 전투가 구현된 뒤 다음은 사용자 체감 테스트가 필요하다.
- 일일 던전 3~5분이 지루한지
- 보스 90초가 짧거나 긴지
- 비동기 아레나가 전투력 숫자 싸움처럼 느껴지는지
- 탑 10층 단위 보스 리듬이 반복적으로 느껴지는지

현재 문서 단계에서는 직접 테스트 불필요.
