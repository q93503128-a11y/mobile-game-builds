# Stackfall Mobile 개발 로드맵

현재 단계: `Phase 1 combat core complete → full mobile presentation shell integration`

엔진: `Unity 6000.3.19f1 / C#`

원칙: 콘텐츠를 많이 만드는 것보다 먼저 코어 전투와 데이터 구조가 맞는지 검증한다. 임시 구현을 쌓은 뒤 나중에 갈아엎는 방식은 피한다. Unity는 매 작업마다 열지 않되, 사용자 첫 테스트는 단순 전투 원형이 아니라 모바일 게임으로서 최소 구색을 갖춘 뒤 진행한다.

## Phase 0 — 정본/연구 고정 ✅

완료:
- 기존 웹 Stackfall 기능 전수 분류
- 경쟁작 수치/경제/콘텐츠 벤치마크
- 모바일 플랫폼 요구사항
- Unity 프로젝트 구조/검증 정책
- 6부품/S 24부품/가챠/경제 V0
- 12개 공격 6단 진화
- Stage 1~50 능력 순차 해금
- 액티브/지원 후보 덱 구조
- 초기 8챕터/적/엘리트/보스
- 홈/격납고 정보구조
- 던전/랭킹/탑/아레나/길드 기획
- 길드/채팅/모더레이션
- 데이터 스키마/정적 검증기

## Phase 1A — 전투 코어 소스 ✅

소스 구현:
- 모바일 드래그 이동 + 키보드 확인 입력
- 자동 조준
- 적/경험치/투사체/중력장 풀링
- 일반 웨이브/엘리트/5분 보스
- 엘리트 예고 돌진
- 보스 광역 펄스/돌진
- 경험치/레벨업/3택
- 코어 펄스 / 펄스 블레이드 / 중력 우물
- 선체/동력/타이머/보스 체력 HUD
- 클리어/실패
- 위험 시각표현/판정 반경 정합
- Runtime source hygiene + Actions 정적 검사

이 코어는 아직 사용자 첫 플레이 테스트 대상으로 넘기지 않는다.

40. 우편 / 임무 / 출석 / 무료 보급 수령 상태와 홈·상단 알림 배지 동기화
41. `validate_first_test_readiness.py` — Unity 버전·changeset / 셸 소스 / 외부 아이콘 / Stage 1~2 게이트 / 문서 중복 / 알림 상태 정적 프리플라이트

source-only 게이트는 완료했다. 남은 게이트는 Unity 6000.3.19f1에서 실제 import/compile 및 Play Mode 화면 검증이다. 이 검증 전에는 Phase 1B를 최종 완료로 판정하지 않는다.

첫 테스트에서는 회수/도전/길드의 실제 서버 기능은 필요 없지만, 플레이어 화면에는 개발 상태 문구를 노출하지 않는다. 현재 소스는 해당 메뉴를 정상적인 스테이지 잠금 조건으로만 표현한다.
