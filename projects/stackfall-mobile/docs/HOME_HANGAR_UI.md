# Stackfall Mobile 홈/격납고 UI 정본

상태: `v0.1 — Phase 0`

목적: 모바일 라이브서비스 게임에 필요한 높은 정보 접근성과 강한 성장/상품 노출을 유지하면서도, 화면이 배너와 빨간 점으로 무너지는 것을 방지한다. 플레이어가 가장 먼저 보는 것은 `기체`이며, 상점과 이벤트는 그 주변에서 접근하게 한다.

## 1. 최상위 원칙

- 세로 화면 기준.
- 중앙 주인공은 현재 장착 부품이 실제 반영된 기체.
- 홈은 `격납고`로 표현한다.
- 첫 화면에서 가장 큰 CTA는 항상 현재 메인 스테이지 진입.
- 개발 상태, 테스트 상태, 내부 버전명, TODO, 디버그 문자열은 노출하지 않는다.
- 한 화면에서 동시에 강하게 강조하는 구매 CTA는 최대 2개.
- 빨간 점은 `받을 수 있는 보상/무료 행동/실제 미확인 변화`에만 사용한다.
- 단순히 상점에 상품이 존재한다는 이유로 영구 빨간 점을 유지하지 않는다.

## 2. 하단 기본 탭

1. `전투`
2. `기체`
3. `회수`
4. `도전`
5. `길드`

탭은 엄지손가락으로 누르기 쉬운 하단 고정형을 기본으로 한다.

### 전투

- 현재 챕터/스테이지
- 권장 전투력
- 예상 주요 보상
- 전투 버튼
- 좌우로 이전/다음 스테이지 확인
- 챕터 보스는 일반 스테이지보다 카드 크기와 배경을 다르게 표시

### 기체

- 6부품 장착
- 프리셋
- 슬롯 강화
- 부품 승급/돌파
- 상세 스탯
- 외형 확인

### 회수

- 표준 회수
- 프로토타입 공명
- 기간 한정 배너
- 천장/보장 카운트 명시
- 확률표 접근
- 조율 데이터/교환 접근

### 도전

- 일일 던전
- 보스 격파전
- 무한 탑
- 아레나
- 기간 이벤트

잠금 콘텐츠는 잠금 이유와 해금 조건만 보여주며 `개발 중` 같은 문구는 쓰지 않는다.

### 길드

미가입:
- 추천 길드
- 검색
- 생성

가입:
- 출석
- 기부
- 연구
- 길드 보스
- 길드 상점
- 길드 채팅
- 길드 랭킹

## 3. 홈 화면 구성

상단:
- 프로필 아이콘/닉네임
- 전투력
- 에너지(채택 시)
- 크레딧
- 크리스탈

중앙:
- 실제 조립 기체
- 배경 정비 베이
- 장착한 Drive/Orbiter/Reactor의 움직이는 요소
- 탭/드래그로 제한적 회전 또는 각도 변화

중앙 하단:
- 현재 `Stage X-Y`
- 스테이지 명
- 권장 전투력
- `전투` 대형 버튼

측면 접근:
- 출석
- 임무
- 이벤트
- 시즌 패스
- 한정 패키지
- 우편

측면 아이콘은 화면을 침범하지 않도록 접이식 스택을 허용한다.

## 4. 격납고 기체 표현

기체는 부품 장착 결과가 즉시 보인다.

- Core: 중앙 발광/눈/심장부
- Frame: 전체 실루엣
- Drive: 하단/후면 이동기관
- Impactor: 전면 구조
- Orbiter: 실제 공전체
- Reactor: 후면 에너지 장치

S★2/신화/초월 변형은 홈에서도 확인 가능해야 한다.

외형 확인 모드:
- UI 최소화
- 회전/확대
- 부품별 하이라이트
- 현재 외형 단계 표시

## 5. 전투력 표시

전투력은 한 숫자로 보여주되 상세 화면에서 구성요소를 분해한다.

예:
- 기본 출력
- 생존력
- 기동
- 부품 고유효과
- 세트 효과

전투력 숫자가 실제 전투 성능과 완전히 일치하지 않을 수 있으므로 `보스 특화`, `생존 특화` 같은 태그도 병행한다.

## 6. 기체 화면

중앙: 조립 기체
주변 6방향 슬롯:
- Core
- Frame
- Drive
- Impactor
- Orbiter
- Reactor

부품 선택 시:
- 현재 vs 후보 비교
- 기본 스탯 차이
- 고유효과
- 세트 효과
- 외형 미리보기
- 장착
- 강화/돌파 접근

자동 추천은 제공하되 `전투력 가장 높은 장비`와 `현재 빌드 추천`을 구분한다.

## 7. 프리셋

기본 3개 프리셋을 목표로 한다.

- 메인
- 보스
- 아레나

추가 프리셋은 후기 보상/계정 성장으로 열 수 있으나 필수 과금벽으로 만들지 않는다.

프리셋 저장 대상:
- 6부품
- 지원 프로토콜
- 후기 데이터칩/유물 계통

슬롯 레벨은 공유하므로 프리셋별로 중복 강화하지 않는다.

## 8. 상점/상품 노출 규칙

상품은 다음 이벤트에서 자연스럽게 노출할 수 있다.

- 첫 S 획득 후 S 성장 패키지
- 챕터 보스 최초 클리어 후 챕터 성장 패키지
- 천장 도달 근처의 소환 패키지
- 시즌 시작 시 패스
- 특정 성장 재료 부족 시 관련 재료 패키지

금지:
- 전투 중 강제 구매 팝업
- 실패 직후 닫기 어려운 다중 팝업
- 무료 버튼과 결제 버튼을 혼동시키는 배치
- 가격/내용이 불명확한 CTA

## 9. 알림 배지 규칙

빨간 점 허용:
- 무료 소환 가능
- 보상 수령 가능
- 강화 가능하고 필요한 재료가 충분함
- 이벤트 새 보상 도달
- 길드 보상 수령 가능
- 읽지 않은 우편

빨간 점 금지:
- 단순 신규 유료 상품
- 항상 열려 있는 상점
- 이미 확인한 기능

## 10. 팝업 우선순위

접속 직후 자동 팝업은 최대 2단계.

우선순위:
1. 필수 계정/서비스 공지
2. 기간 만료 임박 보상
3. 출석/무료 보상
4. 시즌/이벤트 안내
5. 상품 안내

상품 팝업은 매 접속마다 반복하지 않고 노출 제한을 둔다.

## 11. 모바일 접근성/가독성

- 중요 터치 목표 최소 48dp 수준 우선
- 한 손 엄지 기준으로 핵심 CTA를 하단 60%에 배치
- 노치/카메라홀/홈 인디케이터 세이프에어리어 준수
- 중요한 숫자는 색만으로 희귀도/증감을 전달하지 않음
- 긴 설명은 접기/상세로 분리
- 360×640급 작은 화면에서도 하단 탭과 전투 CTA가 겹치지 않게 함

## 12. 사용자 테스트 게이트

실제 Unity UI 프로토타입이 나오면 사용자 확인이 필요한 항목:
- 한 손으로 전투/기체/회수/도전 이동이 편한지
- 화면이 과도하게 양산형 배너로 답답해 보이지 않는지
- 조립 기체 외형 변화가 충분히 눈에 띄는지
- 스테이지 진입 버튼을 즉시 찾을 수 있는지

이 문서 단계에서는 사용자 직접 테스트가 필요하지 않다.
