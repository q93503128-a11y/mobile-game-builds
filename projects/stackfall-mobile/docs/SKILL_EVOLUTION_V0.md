# Stackfall Mobile 전투 스킬 6단 진화 V0

상태: `Phase 0 내부 기획 정본`

목적: 기존 웹 Stackfall의 `같은 공격을 중첩할수록 수치뿐 아니라 동작 단계가 달라지는 재미`를 모바일 스테이지형 성장으로 변환한다.

## 1. 공통 구조

공격 능력은 전투마다 초기화되며 최대 6랭크까지 성장한다.

- Rank 1 — 능력 획득
- Rank 2 — 기본 성능 강화
- Rank 3 — 첫 행동 변화
- Rank 4 — 행동 변화 강화
- Rank 5 — 두 번째 행동 변화
- Rank 6 — `극성화` 최종 형태

단순 `피해 +10%`만 6번 반복하지 않는다.

공격 슬롯 최대 6개. 지원 프로토콜 슬롯 최대 4개.

지원 프로토콜은 공격 진화에 필수 재료로 강제하지 않는다. 특정 조합은 강한 시너지를 만들 수 있지만 잘못된 지원 선택 때문에 Rank 6 자체가 잠기지는 않는다.

## 2. 레벨업 선택 규칙

기본 3택.

가중치 원칙:
- 빈 공격 슬롯이 있으면 신규 공격이 일정 확률 등장
- 이미 보유한 공격은 업그레이드 후보로 등장
- Rank 6 공격은 더 이상 일반 업그레이드 풀에 등장하지 않음
- 같은 카드가 세 칸에 중복 등장하지 않음
- 3회 연속으로 보유 공격 업그레이드가 하나도 나오지 않으면 다음 선택에서 최소 1개 보정

목적: 랜덤 빌드는 유지하되 플레이어가 만든 방향을 게임이 완전히 무시하지 않게 한다.

# 15. 지원 프로토콜 성장 규칙

지원 프로토콜은 최대 Rank 5.

첫 범위:
- 출력 증폭
- 가속 회로
- 벡터 부스터
- 취약점 해석
- 충격 흡수재
- 자가 복원
- 성운 통찰
- 광자 팽창
- 광자 가속
- 심우주 조준기
- 다중 투영
- 거성 사냥
- 연쇄 과부하
- 연쇄 추진
- 연쇄 회수
- 전리품 공명

지원 프로토콜의 각 선택은 일반적으로 한 번에 5~15%급 효율을 사용한다.

`다중 투영`처럼 행동을 바꾸는 프로토콜은 낮은 등장 확률 또는 최대 랭크 제한을 사용한다.

# 16. 극성화 카드 등장

Rank 5 공격을 보유하면 다음 레벨업부터 해당 공격의 Rank 6 극성화 카드가 등장 가능하다.

보정:
- Rank 5 공격을 얻은 뒤 4번의 레벨업 동안 극성화가 한 번도 등장하지 않았다면 5번째 선택에서 최소 1개 극성화 후보 보장
- 여러 Rank 5가 있으면 균등하게 보정

한 판에서 모든 공격을 Rank 6로 만드는 것을 기본 기대값으로 두지 않는다.

10분 표준 스테이지 목표:
- 완성된 Rank 6 공격: 2~4개
- Rank 4~5 보조 공격: 1~3개
- 지원 프로토콜: 4슬롯 대부분 Rank 2~4

# 17. 밸런스 검증

각 공격은 다음 네 상황에서 비교한다.

- 다수 잡몹 DPS
- 보스 단일 DPS
- 이동 중 유효 명중률
- 화면/CPU 비용

한 공격이 네 지표 모두 상위권이면 수치 또는 유틸리티를 줄인다.

극성화는 Rank 5 대비 실전 기여가 대략 20~40% 상승하는 범위를 첫 목표로 하되, 단순 피해량만 40% 올리지 않고 행동 개선을 포함한다.
