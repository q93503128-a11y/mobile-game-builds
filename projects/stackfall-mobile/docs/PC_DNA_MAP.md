# Stackfall PC/Web → Mobile DNA 전수 분류

상태: `Phase 0 정본`

목적: 기존 `q93503128-a11y/Stackfall`의 기능을 모바일판으로 옮길 때 무엇을 보존하고 무엇을 재설계할지 명시한다. 기존 코드를 그대로 포팅하지 않는다.

분류:
- `KEEP DNA` — 핵심 전투 정체성을 유지한다.
- `MOBILE REDESIGN` — 개념만 유지하고 입력·사거리·빈도·가독성·성능을 모바일 기준으로 다시 만든다.
- `META CONVERT` — 전투 중 랜덤 성장보다 영구 부품/연구/수집 성장으로 옮긴다.
- `DROP` — 모바일 정본에서 제거한다.
- `RESEARCH` — 프로토타입 후 유지 여부를 결정한다.

|---|---|---|

### 공격 정본 원칙

1. 공격 계통은 이름보다 **행동 차이**를 보존한다.
2. 같은 표적을 노리는 집중형 공격은 불필요하게 여러 적으로 분산하지 않는다.
3. 레벨업/진화 시 단순 `피해 +N%`만 반복하지 않고 발사 형태·표적 규칙·궤도·상태가 최소 한 번 이상 변한다.
4. 강해질수록 화면을 가리는 방식으로 성장시키지 않는다.

### 패시브 정리 원칙

- `공격력 +10%`, `HP +10%`, `피해감소 +N%`처럼 영구 부품이 담당할 수 있는 단순 수치는 메타 성장으로 우선 이동한다.
- 전투 내 카드에는 **플레이 방식 변화, 조건부 폭발, 리스크-리턴, 공격 계통 시너지**를 우선 배치한다.
- 성장 선택지를 많이 보이게 하려고 의미 없는 카드 수를 늘리지 않는다.

## 5. 모바일판에서 폐기하는 PC 전제

- 마우스 포인터 기반 정밀 수동 조준
- 900px 이상 긴 사거리 자체를 강함의 핵심으로 삼는 설계
- 브라우저 로컬 저장을 영구 계정 데이터의 권위로 사용하는 구조
- PC 화면에서만 읽히는 작은 텍스트/표시
- 동일 공격체를 무제한 늘려 성장을 표현하는 방식
- 무한 생존 기준으로만 밸런싱된 8분/16분/24분 스케일링
- 장시간 플레이를 전제로 한 고정 회복량/쿨다운 값을 그대로 재사용

## 6. Phase 0 결론

웹 Stackfall에서 모바일로 보존할 가장 중요한 DNA는 다음 8개다.

1. 한 표적에 화력이 모이는 `집중`
2. 플레이어 주위를 도는 `공전`
3. 적 무리를 모으는 `중력`
4. 여러 적 사이를 이동하는 `연쇄`
5. 곡선 왕복하는 `부메랑`
6. 독립 편대가 싸우는 `드론`
7. 일직선으로 다수를 가르는 `관통/광선`
8. 같은 능력을 여러 번 선택하면 행동 단계가 달라지는 `중첩 진화`

모바일판의 첫 전투 프로토타입은 이 중 `집중 / 공전 / 중력 / 드론`을 우선 구현하고, 서로 다른 네 가지 공격 행동이 작은 화면에서도 명확히 구분되는지 검증한다.
