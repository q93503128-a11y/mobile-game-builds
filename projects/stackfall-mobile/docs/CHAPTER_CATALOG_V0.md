# Stackfall Mobile 초기 8챕터 카탈로그 V0

상태: `Phase 0 내부 기획 정본`

목적: 첫 Unity 프로토타입 이후 바로 콘텐츠 생산으로 넘어갈 수 있도록 1~8챕터의 역할, 적, 엘리트, 보스, 환경 규칙을 정의한다.

공통 제작 규칙은 `CHAPTER_ENEMY_BOSS_RULES.md`를 따른다.

# Chapter 1 — 폐기 궤도장

목표: 이동/자동공격/레벨업/엘리트/보스의 기본 문법을 가르친다.

환경:
- 큰 잔해는 충돌하지 않고 배경으로만 사용
- 작은 폐기 컨테이너 일부만 실제 장애물
- 안전 공간을 넓게 유지

적:
- 스크랩 비트: Swarm, 천천히 직진
- 폐기 경비기: Bruiser, 느린 근접
- 낡은 터렛: Shooter, 정지 후 단발
- 충돌 드론: Charger, 긴 예고 후 직선 돌진

엘리트:
- 강화 충돌 드론: 돌진 후 짧은 충격파
- 중장 경비기: 주기적 전면 보호막

중간보스:
- 폐기 압축기
  - 넓은 전방 압착
  - 작은 스크랩 비트 소환
  - 느린 회전 팔

챕터 보스: `궤도 해체자 K-01`

패턴:
1. 양팔 직선 쓸기
2. 3방향 폐기탄
3. 화면 외곽에서 중앙으로 압축선
4. 35% 이하에서 충돌 드론 2기 소환

학습 포인트:
- 큰 공격 예고를 보고 피하기
- 잡몹과 보스 표적 우선순위 이해

# Chapter 2 — 채굴 위성

목표: 포격/지형 압박/우선 처치 적 도입.

환경:
- 채굴 레일이 이동 경로를 시각적으로 구분
- 일정 시간 후 사라지는 낙석 예고

적:
- 광맥 벌레: Swarm, 곡선 접근
- 굴착기: Bruiser, 짧은 전방 드릴
- 채굴 포대: Artillery, 지면 원형 예고
- 운반기: Support, 주변 적 이동속도 +10%
- 폭약 드론: Zone, 사망 후 작은 폭발

엘리트:
- 과열 굴착기: 드릴 후 바닥 열선
- 장갑 포대: 첫 공격 전 보호막

중간보스:
- 굴착 감독기
  - 직선 레이저
  - 낙석 3연속
  - 운반기 호출

챕터 보스: `심층 굴착체 모라`

패턴:
1. 지면 아래 이동 후 예고 지점 돌출
2. 십자형 파쇄파
3. 외곽→내부 낙석
4. 70%/35%에 광맥 벽 생성, 이동 통로 변경

핵심:
- 직접 HP 상승보다 이동 공간 변화로 난도 증가

# Chapter 3 — 냉각 시설

목표: 느린 장판/이동 계획/원거리 혼합.

환경:
- 냉각 누출 지대: 안에 오래 있으면 이동속도 점진 감소, 즉시 빙결 없음
- 푸른 위험 표현은 아군 효과와 명도/형태로 구분

적:
- 냉각 비트: Swarm
- 동결 포드: Shooter, 느린 투사체
- 냉각 수리기: Support, 주변 적에게 임시 보호막
- 서리 추적기: Hunter, 플레이어 이동 방향 앞쪽을 노림
- 냉매 분사기: Zone, 짧은 부채꼴 감속 지대

엘리트:
- 결빙 추적기: 이동 경로에 짧은 냉각 흔적
- 보호 포드: 주변 적 보호막 + 본체는 약함

중간보스:
- 냉각 관리자
  - 회전 분사
  - 안전 부채꼴 1개만 남기는 냉각 파동
  - 수리기 소환

챕터 보스: `극저온 코어 헬리온`

패턴:
1. 4방향 냉각 광선 회전
2. 순차 원형 장판
3. 냉각 기둥 3개 생성, 파괴 시 안전구역 확대
4. 35% 이하에서 광선 회전 방향 주기적 반전

보스는 플레이어를 완전 빙결시키지 않는다.

---

# Chapter 4 — 붉은 정제소

목표: 폭발 연쇄와 빠른 돌진 압박.

환경:
- 열 배관 파열 지점 예고
- 폭발성 탱크는 플레이어/적 모두 피해 가능하지만 보스에는 제한 피해

적:
- 열충 드론: Swarm
- 슬래그 러너: Charger
- 압력 포대: Artillery
- 연료 운반체: Splitter/폭발
- 정제 감시기: Shooter, 3연사

엘리트:
- 과압 러너: 돌진 종료 폭발
- 연료 감독기: 주변 폭발성 적 강화

중간보스:
- 정제 압력체
  - 원형 충격파
  - 압력 포대 배치
  - 폭발 탱크 밀어냄

챕터 보스: `용광로 집행자 베르크`

패턴:
1. 전방 화염 절단 3연격
2. 열구역 3개 순차 생성
3. 중앙 점프 후 원형 파동
4. 70% 이하 팔 한쪽 과열: 해당 방향 패턴 강화
5. 35% 이하 양팔 과열, 대신 휴식 간격 증가

---

# Chapter 5 — 중력 연구소

목표: 위치 제어, 끌어당김/밀어냄, 중력 빌드의 보스 변환 규칙 학습.

환경:
- 약한 중력 패널: 이동 방향을 살짝 휘게 함
- 강제 이동은 짧고 예측 가능하게 제한

적:
- 질량 비트: Swarm
- 중력 노드: Zone, 작은 흡인
- 반발기: Disruptor, 부채꼴 밀침
- 궤도 포탑: Shooter, 회전 사격
- 질량 운반체: Bruiser, 주변 적 무게 증가로 넉백 저항

엘리트:
- 과밀 노드: 흡인 + 종료 폭발
- 반발 수호기: 전면 방어 + 밀침

중간보스:
- 궤도 실험체
  - 플레이어 주변을 도는 소형 노드 3개
  - 중앙 흡인 후 외곽 안전지대
  - 회전 탄막

챕터 보스: `중력 원환체 아트라`

패턴:
1. 중앙 특이점 생성
2. 외곽 반발파
3. 회전하는 두 개의 중력축
4. 70% 이하 중력 방향 반전 패턴 추가
5. 35% 이하 특이점 2개 동시 생성, 서로 합쳐지기 전 파괴 가능

중력붕괴 세트의 보스 흡인은 피해 표식으로 변환되어 작동.

---

# Chapter 6 — 파손 함대

목표: 원거리 포화, 지원기 우선 처치, 이동하는 전장 느낌.

환경:
- 배경 함선이 이동해 방향감을 제공
- 실제 전투영역은 안정적으로 유지
- 일정 구간에서 측면 포격 예고

적:
- 요격기: Hunter
- 함대 사수기: Shooter
- 미사일 보트: Artillery
- 수리 드론: Support/Heal
- 방패 호위기: Shield
- 자폭 요격기: Charger

엘리트:
- 지휘 요격기: 주변 사격 주기 강화
- 장갑 미사일 보트: 첫 미사일 후 방어 해제

중간보스:
- 호위함 파편체
  - 측면 포대 2개
  - 수리 드론 호출
  - 직선 미사일 장벽

챕터 보스: `파손 순양함 노마드`

구조:
- 보스 본체 + 좌/우 포대
- 포대 파괴 시 해당 방향 패턴 약화

패턴:
1. 측면 탄막
2. 유도 미사일 3발
3. 중앙 주포 긴 예고
4. 수리 드론 소환
5. 35% 이하 후퇴하며 전진 포격, 플레이어가 따라가는 느낌의 카메라 이동

---

# Chapter 7 — 공허 경계

목표: 위상 이동, 잔상, 순간 위치 변화에 대응.

환경:
- 배경 일부가 끊겨 보이는 시각효과
- 실제 충돌 경계는 명확하게 표시

적:
- 공허 조각: Swarm, 짧은 순간이동
- 위상 사수: Shooter, 투사체가 1회 사라졌다 재등장
- 공허 사냥꾼: Hunter
- 잔상체: Splitter, 사망 시 약한 잔상 1개
- 틈새 노드: Zone, 좁은 순간이동 구역

엘리트:
- 쌍위상 사수: 두 위치를 번갈아 사용
- 공허 사냥꾼: 돌진 후 잔상 공격

중간보스:
- 경계 감시자
  - 순간이동 후 부채꼴
  - 잔상 2개와 본체 구분
  - 화면 가장자리 균열

챕터 보스: `무형 포식자 니힐`

패턴:
1. 위치 예고 후 순간이동 베기
2. 4개 잔상 생성, 진짜 본체만 약한 왜곡 표시
3. 공허선이 화면을 순차 절단
4. 70% 이하 잔상 1개가 별도 공격
5. 35% 이하 본체/잔상 위치 교환 속도 증가

공허 세트가 강하지만 보스의 전역 절단선은 완전 무시하지 못함.

# Chapter 8 — 성간 묘지

목표: 앞 7챕터 역할을 혼합하는 첫 대형 종합시험.

환경:
- 거대 함선 잔해가 전장을 나누는 구간
- 주기적으로 잔해 파편이 지나가지만 충분한 예고 제공

적:
- 묘지 비트: Swarm
- 잔해 수호기: Bruiser
- 유령 포대: Shooter
- 파편 투척기: Artillery
- 재생 노드: Support
- 파멸 추적기: Hunter

엘리트:
- 고대 수호기: 보호막 + 느린 광선
- 파멸 추적기: 돌진 + 잔류 파편

중간보스:
- 무덤 파수함
  - 포대/추적기 혼합
  - 일정 HP마다 잔해 방벽 생성

챕터 보스: `성간 장례자 에레보스`

정체성:
- 첫 8챕터의 대표 위험을 섞되 한꺼번에 사용하지 않음

Phase 1:
- 직선 관통광선
- 느린 추적탄

Phase 2:
- 작은 중력장
- 파편 낙하
- 지원기 소환

Phase 3:
- 공허 순간이동
- 회전 절단선
- 이전 패턴 중 1개를 무작위 조합

규칙:
- 동시에 핵심 위험 최대 2종
- 조합 사이 최소 휴식 1.2초
- 보스 사망 직전 무적 연출 없음

# 9. 스테이지 배치 초안

각 챕터 10스테이지:

- X-1: 대표 일반 적 2종
- X-2: 원거리/돌진 역할 추가
- X-3: 환경 규칙 첫 노출
- X-4: 3역할 혼합
- X-5: 엘리트
- X-6: 지원/제어 적 추가
- X-7: 환경 + 엘리트 변형
- X-8: 높은 밀도 조합
- X-9: 중간보스/특수 목표
- X-10: 챕터 보스

Chapter 1은 튜토리얼성을 위해 더 완만하게 조정한다.

# 10. 재사용 원칙

- Chapter 3 이후 이전 챕터 적 1~2종을 새로운 조합으로 재사용 가능
- 색만 바꾼 동일 적을 신규 적으로 세지 않음
- 재사용 적이 새 챕터의 전용 적보다 더 강한 핵심 기믹을 가져가지 않게 함
- 이전 보스를 일반 적으로 축소 재활용하지 않음

# 11. 제작 우선순위

Unity Phase 1에서 실제 제작할 최소 세트:

- Chapter 1 배경 규칙
- 일반 적 4종
- 엘리트 1종
- 보스 `궤도 해체자 K-01`
- 5~7분짜리 Stage 1-1 또는 전투 테스트 스테이지

Chapter 2~8은 데이터/콘셉트 정본으로 유지하고 Phase 1 전투가 검증된 뒤 제작한다.
