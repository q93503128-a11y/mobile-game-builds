# Stackfall Mobile 길드/채팅 정본 V0

상태: `Phase 0`

목적: 장기 경쟁과 커뮤니티 동기를 만들되, 운영/모더레이션/스팸/치팅 문제를 초기에 구조적으로 막는다.

## 1. 길드 기본

- 기본 정원: 30명
- 성장에 따라 최대 40명까지 확장 후보
- 공개 / 승인제 / 비공개 초대형
- 길드 레벨 존재
- 길드 경험치는 출석, 기부, 길드 보스, 길드 임무에서 획득

## 2. 길드 역할

- 길드장
- 부길드장
- 운영진
- 일반 길드원

권한:
- 가입 승인
- 추방
- 공지 수정
- 연구 선택
- 길드전/레이드 참가 설정

길드장 권한을 단일 장치에 묶지 않고 부길드장 위임 가능.

## 3. 길드 출석

하루 1회.

보상:
- 개인: 길드 코인
- 길드: 경험치/활동도

누적 출석 인원 보상:
- 5명
- 15명
- 25명

개별 과금보다 참여 인원을 장려한다.

## 4. 길드 기부

기부 수단:
- 크레딧
- 제한적 크리스탈 기부

크리스탈 기부는 일일 상한을 둔다.

기부 보상:
- 길드 코인
- 연구 포인트
- 활동도

고과금 유저 한 명이 연구를 즉시 끝내지 못하도록 일일 개인 상한을 둔다.

## 5. 길드 연구

트리 예시:
- 일반 공격 출력
- 보스 피해
- 최대 HP
- 크레딧 획득량
- 길드 보스 보상
- 길드 상점 갱신

길드 연구는 전체 계정 성장에서 유의미하지만, 길드 미가입 사용자가 메인 스테이지를 못 깨는 수준의 필수 배율은 금지.

## 6. 길드 상점

재화: 길드 코인.

판매 후보:
- 승급 재료
- 일반 회수 티켓
- 아레나/보스 티켓
- 선택형 일반 부품 조각
- 조율 데이터 소량

S 완제품 상시 판매는 하지 않는다.

## 7. 길드 보스

상세 전투 규칙은 `CHALLENGE_MODES_V0.md`를 따른다.

길드 화면에서:
- 남은 시간
- 개인 최고 기록
- 길드 누적 피해
- 다음 마일스톤
- 길드 내 피해 순위

를 즉시 확인 가능.

## 8. 길드 랭킹

항목:
- 총 전투력
- 주간 활동도
- 길드 보스 피해
- 시즌 길드전 점수

국가/글로벌 필터를 제공.

## 9. 채팅 채널

초기:
- 글로벌
- 국가
- 길드

후기:
- 귓속말
- 친구
- 파티/레이드 임시 채널

## 10. 시스템 메시지

허용 예:
- 희귀 S/초월 부품 획득
- 서버 최초 챕터 보스 클리어
- 탑 특정 마일스톤
- 길드 레이드 기록

과도한 광고처럼 느껴지지 않도록 동일 종류 공지 빈도 제한.

예:
`[System] KOR-127님이 초월 등급 중력붕괴 코어를 완성했습니다.`

개발자 메모, 내부 ID, 서버 로그, 오류 스택은 절대 시스템 메시지로 노출하지 않는다.

## 11. 채팅 UX

- 전투 중에는 전체 채팅창 자동 표시 금지
- 홈 하단에 최근 한 줄 프리뷰 선택 가능
- 채팅 화면에서 채널 탭 전환
- 링크는 화이트리스트 방식 또는 비활성화 우선
- 반복 메시지 접기

## 12. 스팸 방지

- 초당/분당 전송 제한
- 동일 문구 반복 제한
- 신규 계정 글로벌 채팅 제한 후보
- 의심 계정 쿨다운
- 서버측 rate limit

클라이언트만으로 제한하지 않는다.

## 13. 신고/차단

신고 사유:
- 욕설/혐오
- 스팸
- 사칭
- 외부 거래/도박
- 성적/불법 콘텐츠
- 기타

차단:
- 개인 메시지 숨김
- 글로벌/국가/길드 표시 숨김
- 시스템 공지는 차단 대상이 아님

신고 데이터는 서버에 최소 필요 범위로 보관하고 운영자가 문맥을 확인할 수 있게 메시지 ID/채널/시간을 남긴다.

## 14. 닉네임/길드명

- 길이 제한
- 금칙어 검사
- 제어문자/제로폭 문자 악용 방지
- 대소문자/유니코드 동형문자 사칭 완화

국가 채널은 계정 국가/스토어 지역/선택 지역 정책을 별도로 확정해야 한다.

## 15. 길드전 후기 구조

초기 길드 시스템 안정 후 도입.

후보:
- 주간 비동기 거점전
- 여러 보스에 길드원 공격 배분
- 방어 기체 배치
- 총점 경쟁

실시간 대규모 PvP는 초기 범위에서 제외.

## 16. 사용자 테스트 게이트

서버/클라이언트 최소 기능이 생긴 뒤 테스트 필요:
- 글로벌/국가/길드 전환이 직관적인지
- 채팅이 홈 UI를 방해하는지
- 길드 보스 보상과 개인/길드 기여가 이해되는지

현재 기획 단계에서는 사용자 테스트 불필요.
