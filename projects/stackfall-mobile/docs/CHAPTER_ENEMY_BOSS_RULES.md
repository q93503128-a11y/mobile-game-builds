# Stackfall Mobile 챕터·적·보스 제작 규칙

상태: `Phase 0 내부 기획 정본`

목적: 메인 스테이지를 수백 개까지 확장해도 단순 수치 복붙이나 화면 과밀로 흐르지 않도록 제작 규칙을 고정한다.

## 1. 챕터 기본 단위

초기 제작 기준은 `1챕터 = 10스테이지`다.

권장 흐름:

- 1~4: 일반 진행 + 새 적/패턴 학습
- 5: 엘리트 스테이지
- 6~8: 조합 난도 상승
- 9: 보스 직전 압박/특수 규칙
- 10: 챕터 보스

모든 챕터가 완전히 같은 템플릿처럼 느껴지지 않도록 3~4개 챕터마다 구조 변형을 넣는다.

변형 후보:
- 연속 엘리트
- 방어/영역 유지
- 이동형 목표
- 보스 추격
- 제한된 안전구역
- 자원 회수 + 생존

## 2. 스테이지 시간

메인 진행 기준:

- Chapter 1~2: 5~7분
- Chapter 3~5: 6~8분
- 중반 이후 일반: 7~10분
- 챕터 보스: 9~12분
- 특수 고난도: 최대 15분

시간을 늘려 난이도를 만드는 방식을 금지한다.

## 3. 10분 표준 스테이지 리듬

예시:

- 0:00~1:30 — 기본 적, 첫 레벨업 구간
- 1:30 — 첫 압박 웨이브
- 2:30 — 엘리트 1
- 3:30 — 새 조합/지형 규칙
- 5:00 — 이벤트 또는 엘리트 2
- 6:30 — 중간보스 또는 강화 엘리트
- 8:00 — 후반 압박
- 9:20 — 최종 보스 예고/정리 구간
- 10:00 — 보스

실제 스테이지는 ±20% 범위에서 변형한다.

## 4. 적 역할군

적을 외형만 바꾼 HP 덩어리로 만들지 않는다.

### 기본 역할

1. `Swarm` — 약하지만 수가 많음
2. `Bruiser` — 느리고 튼튼한 근접 압박
3. `Charger` — 예고 후 직선 돌진
4. `Shooter` — 단순 원거리 사격
5. `Artillery` — 바닥 예고 후 장거리 포격
6. `Shield` — 전면/방향 방어
7. `Splitter` — 사망 시 소형 개체 분열
8. `Support` — 주변 적 강화/회복/보호
9. `Summoner` — 소형 적 소환
10. `Zone` — 위험지대/장판 생성
11. `Hunter` — 플레이어 이동 방향을 예측해 접근
12. `Disruptor` — 공격/회피 공간을 제한하는 특수 역할

한 적이 너무 많은 역할을 동시에 가지지 않는다.

## 5. 챕터별 적 구성 규칙

한 챕터는 기본적으로:

- 대표 일반 적 3종
- 원거리/제어 적 1~2종
- 엘리트 베이스 2종
- 챕터 전용 적 1종
- 중간보스 후보 1종
- 챕터 보스 1종

을 기준으로 한다.

신규 챕터에서는 적을 전부 새로 만들기보다:

- 기존 적 일부 재사용
- 새 역할 1~2개 추가
- 기존 역할 조합 방식 변화
- 맵/환경 규칙 변화

로 제작량을 관리한다.

## 6. 동시 적 수와 모바일 성능

메인 전투의 실제 게임플레이 개체 기준 V0 목표:

- 일반 구간: 25~45
- 압박 구간: 40~55
- 소프트 캡: 65
- 하드 캡: 80
- 보스전 잡몹: 보스 포함 보통 20~35

스웜 연출에서 100마리처럼 보이게 만들 필요가 있으면 시각 군집/저비용 표현을 사용할 수 있지만 실제 충돌·AI 개체를 무제한 늘리지 않는다.

기기 성능에 따라 실제 적 수나 난이도를 몰래 줄이지 않는다. 저사양 대응은 렌더/VFX/해상도 품질을 낮추는 방향으로 한다.

## 7. 스폰 규칙

금지:
- 플레이어 바로 위 즉시 스폰
- 화면 밖에서 예고 없이 즉발 투사체
- 이동 불가능한 완전 포위 스폰
- 보스 패턴과 일반 적 위험이 같은 색/형태로 겹침

기본:
- 화면 가장자리 스폰은 최소 안전거리 확보
- 돌진/포격은 시각 예고 후 판정
- 위험 방향을 UI/지면 표현으로 읽을 수 있게 함
- 동일 프레임 대량 생성 금지, 여러 프레임으로 분산

## 8. 난이도 상승 수단

적 HP/공격력만 올리지 않는다.

우선순위:
1. 역할 조합
2. 이동 경로 압박
3. 공격 주기
4. 엘리트 조합
5. 안전구역 감소
6. 스폰 방향 변화
7. 특수 목표
8. 마지막으로 기본 스탯 상승

동일 소챕터 일반 스테이지 권장 전투력은 대략 4~8% 체감 상승 범위를 사용하되 실제 난도는 행동 변화와 함께 조정한다.

## 9. 엘리트

일반 적의 단순 HP 10배 버전을 금지한다.

엘리트는 기본 적 역할 + 1개의 명확한 강화 규칙을 가진다.

엘리트 속성 후보:
- 공격 후 잔류 장판
- 사망 폭발
- 주기적 보호막
- 주변 적 가속
- 분열
- 추적탄
- 충격파
- 순간 돌진

동시에 2개 이상을 붙이는 것은 후기 콘텐츠에서만 제한적으로 사용한다.

엘리트 등장 시:
- 실루엣/크기/테두리로 즉시 구분
- 화면 밖이면 방향 표시
- 드랍/경험치 가치가 일반 적보다 명확히 큼

## 10. 보스 제작 규칙

보스는 `큰 HP + 일반 적 공격`이 아니다.

기본 보스는 3~5개의 서로 다른 행동을 가진다.

필수 구성:
- 기본 압박 패턴 1개
- 이동/위치 변화 패턴 1개
- 넓은 위험 예고 패턴 1개
- 페이즈 전환 또는 소환/환경 변화 1개

선택:
- 추적광선
- 부채꼴 탄막
- 돌진
- 안전구역
- 분열체
- 중력/끌어당김
- 회전 공격
- 순차 장판

## 11. 보스 페이즈

일반 기준:
- Phase 1: 100~70%
- Phase 2: 70~35%
- Phase 3: 35~0%

모든 보스가 반드시 3페이즈일 필요는 없다.

페이즈가 바뀌면 최소 하나는 달라져야 한다.
- 공격 조합
- 이동 방식
- 지형
- 안전구역
- 소환 적
- 패턴 속도

단순 공격력 +20%만으로 페이즈를 구분하지 않는다.

## 12. 보스 공격 예고

모바일 기준 일반적인 강공 예고 V0:

- 빠른 소형 공격: 약 0.45~0.70초
- 일반 강공: 약 0.70~1.10초
- 대형/치명적 패턴: 약 1.00~1.60초

플레이테스트로 조정한다.

예고와 실제 피해 영역은 가능한 한 일치한다.

플레이어 VFX가 보스 위험 예고를 덮지 못하게 렌더 우선순위를 분리한다.

## 13. 보스 CC 규칙

보스/중간보스는 다음 강제 제어에 기본 면역:
- 강한 흡인
- 긴 기절
- 이동 봉쇄
- 무한 넉백

대신 해당 빌드가 무효가 되지 않게 변환 효과를 둔다.

예:
- 중력 흡인 → 보스 피해 증폭 표식
- 기절 → 공격속도/패턴 준비시간 약화가 아닌 별도 피해 보너스
- 넉백 → 추가 충격 피해

## 14. 보스 DPS와 시간 제한

일반 챕터 보스는 적정 전투력 기준:

- 평균 플레이어가 90~150초 안에 처치
- 고성장 빌드가 30초 이하로 삭제하지 않도록 페이즈 전환 최소 연출/무적을 남발하지 않고 HP/패턴으로 대응
- 저전투력 유저가 5분 이상 단순 반복하지 않게 제한 시간 또는 강화 패턴 사용

`시간 끌기용 무적`을 반복 사용하지 않는다.

## 15. 챕터 테마 제작 규칙

챕터 테마는 배경색 교체가 아니다.

각 챕터는 최소 다음 중 2개 이상을 가진다.
- 이동 장애물
- 전장 환경 위험
- 적 전용 이동 규칙
- 전용 오브젝트
- 시야/조명 변화
- 목표 규칙 변화

하지만 플레이어의 이동 가능 공간과 적 위험을 구분할 수 있어야 한다.

## 16. 초기 챕터 방향 후보

1. 폐기 궤도장 — 기본 전투/잔해/소형 드론
2. 채굴 위성 — 좁은 광맥/굴착 적/포격
3. 냉각 시설 — 감속 지대/빙결형 기계
4. 붉은 정제소 — 열구역/돌진/폭발
5. 중력 연구소 — 중력장/궤도 변화
6. 파손 함대 — 이동 함선/포탑/지원기
7. 공허 경계 — 위상 적/순간 이동
8. 성간 묘지 — 거대 잔해/엘리트 강화

명칭은 내부 기획명이며 최종 세계관/로컬라이제이션 단계에서 정리할 수 있다.

## 17. 제작 데이터 구조

스테이지는 코드에 직접 적 배열을 하드코딩하지 않는다.

데이터로 최소 다음을 정의한다.
- stage_id
- chapter_id
- duration/goal
- spawn_schedule
- enemy_pool
- elite_rules
- boss_id
- environment_rules
- reward_table
- recommended_power
- allowed_special_rules

적:
- enemy_id
- role
- hp/attack/speed
- collision
- abilities
- drop_profile
- render_profile

보스:
- boss_id
- phase_thresholds
- pattern_pool
- pattern_weights
- cooldowns
- cc_conversion
- enrage_rule

새 스테이지 추가 때문에 핵심 전투 코드를 수정하는 구조를 금지한다.

## 18. 검증 게이트

스테이지/챕터 하나를 완료 처리하기 전에 확인:

- 적과 플레이어 공격이 작은 화면에서 구분되는가
- 화면 밖 공격이 부당하지 않은가
- 피할 공간이 실제로 존재하는가
- 한 역할의 적만 과도하게 반복되지 않는가
- 보스가 HP 덩어리로 끝나지 않는가
- 저사양 성능 목표를 넘지 않는가
- 개발자/테스트용 문구가 플레이 화면에 노출되지 않는가
