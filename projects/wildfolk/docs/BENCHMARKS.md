# 비교군과 참고 범위

## Mine Survival

- 결정 근거: 사용자가 2026-10-13에 주요 UI/UX 비교군으로 지정했다.
- 공식 확인 출처: [WILDSODA의 Google Play 페이지](https://play.google.com/store/apps/details?id=com.WildSoda.MineSurvival).
- 출처 확인일: 2026-10-13.
- 참고 범위: 생존 정보 표시, 모바일 조작 위치, 작은 화면의 오브젝트 구분, 야외 생존 분위기, UI가 플레이 영역을 가리지 않는 정보 위계.
- 현재 적용: Wood/Stone을 고정 재화 HUD에서 제거하고 월드 드랍→획득→인벤토리 재료 아이템으로 연결했다. 좌하단 이동, 우하단 공격, 우상단 가방을 두며 상단 중앙은 평상시 비운다. 어두운 녹회색 UI와 아이콘 중심 슬롯을 사용한다.
- 확실도: 비교군 선정과 원하는 참고 범위는 사용자 요청으로 확정됐다. 이 작업에서 상대 게임의 정확한 UI 좌표·터치 크기·게임 수치를 측정하거나 품질 우열을 검증하지 않았다.
- 복제 금지: 캐릭터·아이콘·배경·애니메이션·문구·맵과 게임 수치를 가져오지 않는다. 현재 시안의 원본은 `tools/generate_visual_assets.py`다.

## surviv.io 계열 실루엣

사용자가 제시한 둥근 몸통과 분리된 작은 손의 즉각적인 가독성을 참고 방향으로 삼았다. 외부 캐릭터 이미지나 고유 장비 자산을 사용하지 않았다. 플레이어의 구체적인 색과 명암, 눈과 주먹은 이번 작업의 독립 시안이다.

현재는 파란 천색 몸통과 피부색 양손으로 회색 석판 인상을 수정하고 실제 교대 공격에 연결했다.

## Minecraft의 월드 아이템 감각

사용자가 파괴 후 바닥 아이템을 접근해 줍는 흐름을 참고하도록 지정했다. 짧은 퍼짐, 접촉 그림자, 약한 bob, 근접 획득으로 2D 탑다운에 적용했다. 실제 Minecraft 아트/텍스처/수치는 사용하지 않았다. 외부 게임 수치를 관측한 벤치마크라고 기록하지 않는다.
