# 비교군과 참고 범위

최신 품질 교정 조사는 [UI_RESEARCH](UI_RESEARCH.md)를 따른다. 아래 각 날짜의 내용은 해당 패스 당시의 참고 기록이다. 세 탭/네 Skill Card는 최신 구현에서 대체했다.

## 2026-10-14 Character / Armor 참고

[Kefir 공식 Last Day on Earth Gear Score 안내](https://kefirgames.helpshift.com/hc/en/5-last-day-on-earth/faq/353-gear-score-gs/)는 캐릭터 Inventory의 장비 슬롯 옆에 비교 수치를 제공한다. Wildfolk는 슬롯/Defense를 같은 화면에서 읽는 정보 구조만 참고한다. 상대 UI 좌표/스킨/아이콘/GS 계산식/성장 수치를 측정하거나 복제하지 않았다. 떠 있는 Profile/세 탭/4 Skill Card/고정 Recipe Sort는 사용자 요구와 자체 구성이다.

## Mine Survival

- 결정 근거: 사용자가 2026-10-13에 주요 UI/UX 비교군으로 지정했다.
- 공식 확인 출처: [WILDSODA의 Google Play 페이지](https://play.google.com/store/apps/details?id=com.WildSoda.MineSurvival).
- 출처 확인일: 2026-10-13.
- 참고 범위: 생존 정보 표시, 모바일 조작 위치, 작은 화면의 오브젝트 구분, 야외 생존 분위기, UI가 플레이 영역을 가리지 않는 정보 위계.
- 현재 적용: 맨손 채집→Wood로 작업대 제작/설치→작업대 도구/검 제작이라는 초반 흐름을 강하게 참고한다. Wood/Stone은 월드 드랍→인벤토리 재료다. 좌하단 이동, 하단 Hotbar 왼쪽 가방, 우하단 사용, 우상단 Pause를 두며 상단 중앙은 평상시 비운다. 자연색 UI/아이콘/단순 Recipe를 자체 구현한다.
- 확실도: 비교군 선정과 원하는 참고 범위는 사용자 요청으로 확정됐다. 이 작업에서 상대 게임의 정확한 UI 좌표·터치 크기·게임 수치를 측정하거나 품질 우열을 검증하지 않았다.
- 복제 금지: 캐릭터·아이콘·배경·애니메이션·문구·맵과 게임 수치를 가져오지 않는다. 초기 시안의 원본은 `tools/generate_visual_assets.py`다. 현재 Armor Overlay/imagegen, Dash/Lucide, 한국어/Noto는 SOURCE_ART를 함께 따른다.

## surviv.io 계열 실루엣

사용자가 제시한 둥근 몸통과 분리된 작은 손의 즉각적인 가독성을 참고 방향으로 삼았다. 외부 캐릭터 이미지나 고유 장비 자산을 사용하지 않았다. 플레이어의 구체적인 색과 명암, 눈과 주먹은 이번 작업의 독립 시안이다.

현재는 사용자 요청에 따라 살구색 원형 몸통/원형 양손/분리된 눈으로 교체했다. 몸통 회전 없이 눈/손이 방향을 표시하고 도구를 손에 부착한다. 원본 에셋을 사용하지 않았다.

## Minecraft의 월드 아이템 감각

사용자가 파괴 후 바닥 아이템을 접근해 줍는 흐름을 참고하도록 지정했다. 짧은 퍼짐, 접촉 그림자, 약한 bob, 근접 획득으로 2D 탑다운에 적용했다. 실제 Minecraft 아트/텍스처/수치는 사용하지 않았다. 외부 게임 수치를 관측한 벤치마크라고 기록하지 않는다.

이번에는 같은 사용자 요청으로 하단 중앙 9칸 Hotbar, 아이콘/수량/선택 표시, 인벤토리 첫 9칸과의 직접 연결, 도구 선택/장착 구조를 참고했다. Wildfolk의 자연색 UI로 다시 구성했으며 상대 게임의 UI 좌표나 수치를 측정/복제하지 않았다.

현재 전체 36슬롯(위 Storage 27, 아래 Hotbar 9), 전체 이동/합치기/교환을 적용했다. 제작 비용 Workbench Wood 6 및 도구/검 Wood 각 5는 사용자 지정 초기값이며 상대 게임에서 관측한 수치라고 주장하지 않는다.

이번 추가도 사용자 지정 맨손→작업대 도구/무기→물/허기·갈증→모닥불 음식 흐름과 화면 가장자리 생존 HUD를 강하게 참고한다. Campfire 비용/5초 조리/소진 시간/회복량은 여유 있는 자체 초기값이고 외부 게임에서 측정한 값이 아니다. Minecraft 멀티 메뉴는 전역 월드를 멈추지 않는 정책 방향만 참고했으며 실제 네트워크는 구현하지 않았다.

이번 사용자 지정 참고 범위는 Wood→Stone→Iron, 낮 채집/건축·밤 Zombie 압박, 기지 방어와 상자 UX까지 확장됐다. 외부 코드/아트/UI를 복제하지 않았다. 초기 장비/Recipe/8분 주기/생성 간격은 Wildfolk 자체 기능 검증값이고 상대 게임의 실제 수치라고 주장하지 않는다. 음향은 사용자의 자연스럽고 물리적인 야외 질감 방향을 정본으로 삼으며 단순 sine/system beep와 억지 임시 BGM을 사용하지 않는다. 현재 적합한 SFX를 추가하지 않고 기존 전자음을 제거했다.

## 2026-10-14 월드/낮밤/입력 패스

Mine Survival은 사용자 지정 극초반 비교 방향이다. 낮 채집·밤 방어·생존/장비 업그레이드/보관의 흐름을 참고하며 수치 측정이나 에셋/코드/UI 복제를 하지 않았다. Seed 월드·원형 캐릭터·분리된Primary/Interact·GameplayLight/인구Budget은 Wildfolk 자체 구현이다. 이번 초깃값은 사용자 테스트 전 자체 기능 검증 값이다.
