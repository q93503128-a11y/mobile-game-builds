# Wildfolk 기획 정본

작성 기준: 2026-10-13. 이 문서는 현재 확정된 방향을 기록한다. 실제 제공 기능은 `main`의 코드와 씬으로 판단한다.

## 확정된 개발 환경

- 프로젝트명: Wildfolk.
- Unity 6000.3.19f1 LTS / Universal 2D.
- 모바일 Landscape. 기준 화면 1920×1080.
- Unity MCP를 통해 에디터 조작과 Game View 검수를 수행한다.

## 현재 게임 방향 — 구현 여부와 구분

탑다운 모바일 생존 게임을 목표로 한다. 1~4인 협동, 무한 생존, 월드 저장 후 이어하기, 채집·아이템 드랍·인벤토리·전투·기지 생존은 현재 지향점이다. 로그라이트 요소를 고려하되 영구 능력치 성장의 비중은 낮게 잡는다. 직업별 고유 특성을 고려한다.

이 항목들은 **계획된 방향이며 현재 구현된 기능이 아니다**. 네트워크, 저장 방식, 직업 종류, 상세 규칙과 밸런스는 아직 확정하지 않았다.

## UI/UX 비교군

Mine Survival을 주요 비교군으로 사용한다. 생존 정보의 모서리 배치, 모바일 조작의 직관성, 자원과 오브젝트의 즉각적인 구분, 야외 생존 분위기, 플레이 영역의 여백을 참고한다. 고유 아트·아이콘·문구·맵을 복제하지 않는다. 더 정돈되고 현대적인 표시를 지향한다. 구체적 참고 범위는 `BENCHMARKS.md`에 기록한다.

## 아트 방향

캐주얼 stylized, 자연스러운 야외 생존, 약간 거칠고 모험적인 분위기를 목표로 한다. 자연색 초록·흙색·회색·목재색과 낮은 채도의 강조색을 사용한다. 읽기 쉬운 실루엣, 절제된 외곽선과 명암, 접촉 그림자로 구분한다.

유아틱한 디자인을 피한다. 병아리·빵·동물 마스코트 같은 플레이어 인상, 볼터치·큰 눈·귀여운 표정, 캔디 광택·네온·파스텔 남발, 장난감 UI와 모든 오브젝트에 얼굴을 붙이는 방향을 사용하지 않는다.

플레이어는 둥근 몸통, 좌우 작은 주먹, 작은 눈 두 개를 가진 맨손 시안이다. 몸통과 손을 독립 요소로 두고 향후 장비 외형을 붙일 위치를 확보한다. 장비 자체는 구현하지 않았다.

## 현재 실제 씬

`client/Assets/Wildfolk/Scenes/WildfolkVisual.unity`가 첫 화면이다.

- 경계가 없는 연속 잔디·흙길 이미지 위에 나무 9그루, 돌 6개, 풀과 고사리, 쓰러진 목재를 배치했다.
- 플레이어 1개, 적 외형 더미 1개가 있다.
- 화면 좌상단에 목재·돌·식량 표시값을 둔다. 중앙 상단은 비워둔다.
- 좌하단 조이스틱, 우하단 주먹 아이콘, 우상단 인벤토리 아이콘을 둔다.
- 플레이어 머리 위 HP 표시가 있다. HUD 수치와 HP는 고정된 시각 자료다.
- CanvasScaler 기준은 1920×1080이고 HUD는 Safe Area 안에 배치한다.
- 카메라는 Orthographic Size 9이며 플레이 영역 높이는 18 월드 유닛이다.

현재 비주얼은 초기 방향성 시안이며 최종 아트가 아니다. 게임 화면에 개발자 안내·테스트 버튼·내부 변수명을 노출하지 않는다.

## 이번 단계에서 제공하지 않는 것

실제 이동/조이스틱 입력, 공격·피격·적 AI, 채집·드랍·인벤토리, 협동 네트워크, 저장·불러오기, 직업, 성장, 보스, 제작·건축, 로그인·상점을 구현하지 않는다. 이 목록은 구현 범위의 경계이며 확정된 향후 출시 기능 목록이 아니다.
