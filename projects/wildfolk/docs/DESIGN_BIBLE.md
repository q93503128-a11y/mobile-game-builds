# Wildfolk 기획 정본

기준일: 2026-10-13. 현재 main의 코드와 씬이 실제 제공 기능의 정본이다.

## 환경과 방향

Wildfolk는 Unity 6000.3.19f1 LTS / Universal 2D, 모바일 Landscape, 기준 1920×1080의 탑다운 생존 게임이다. 현재는 정적 시안을 첫 플레이 가능 버전으로 전환한 단계다.

1~4인 협동, 무한 생존, 월드 저장 후 이어하기, 기지 생존은 지향점이며 구현하지 않았다. 로그라이트 요소를 고려하되 영구 능력치 성장 비중은 낮게 잡고 직업별 특성을 고려한다. 네트워크·저장 형식·직업·성장 규칙은 확정하지 않았다.

## UI/UX와 아트

Mine Survival을 주요 비교군으로 유지한다. 인벤토리 아이템 관리, 화면 가장자리 조작, 중앙 플레이 공간, 작은 화면의 아이콘 가독성을 참고하며 고유 아트와 수치는 복제하지 않는다.

자연색 잔디·흙·목재·회색 돌, 절제된 외곽선과 무광 명암, 접촉 그림자로 약간 거친 야외 생존 분위기를 지향한다. 캔디 광택·네온·파스텔 남발·장난감 UI·동물 마스코트·볼터치·큰 눈을 피한다. 초기 아트이며 최종 아트가 아니다.

플레이어는 중간 채도 파란 천 몸통, 피부색 독립 양손, 작은 눈 두 개다. 회색 석판 같던 몸통을 교체했다. 이동/공격 방향으로 회전하고 약한 이동 bob을 사용하며 양손을 번갈아 뻗는다. 장비/머리 장식 부착 위치는 있으나 실제 장비는 없다.

## 현재 제공하는 흐름

Wildfolk.unity에 플레이어, 기본 적 1개, 나무 9개, 돌 6개, 연속 잔디/길과 자연 디테일을 배치했다. 카메라는 Orthographic Size 9와 부드러운 추적/필드 경계 제한을 사용한다.

- Pointer Down/Drag/Up 아날로그 조이스틱으로 Rigidbody2D 이동. 놓으면 입력과 Thumb 중앙 복귀. WASD 보조 입력.
- 실제 주먹 버튼 입력과 유지 공격. 가까운 공격 가능 대상을 선택하고 모션 중간에 범위를 재확인해 피해 적용. 좌우 교대와 짧은 쿨다운.
- 공통 Health/WorldHealthBar. 플레이어는 항상 표시, 적·나무·돌은 최대 HP에서 숨기고 피해 후 실제 비율 표시, 사망/파괴 시 제거.
- 나무 흔들림, 돌의 단단한 흔들림, 생명체 flash/squash. 공용 Impact 파티클 없음.
- 자원 파괴 시 Wood/Stone 3개가 월드에 튀어나와 그림자/약한 bob으로 남음. 접근 후 획득. 공간 부족이면 수용한 양만 제거하고 잔량 유지.
- ItemDefinition/ItemStack/InventoryModel. 실제 아이템은 Wood/Stone 두 종류. 16슬롯, 자동 스택, 한도 50, 선택과 실제 수량 표시.
- 적 감지→접근→정지→준비→명시적 피해→쿨다운→추적. Trigger/Kinematic으로 플레이어를 밀지 않음. 적 자신의 겹침 해소. 넉백/전리품 없음. HP 0이면 제거.
- BossIdentity 활성화 시 이름/실제 HP를 상단 중앙 HUD에 연결. 보스가 없으면 완전히 숨김. 실제 보스 없음.
- 인벤토리 일시 정지/입력 차단. 사망 후 새 필드 재시작.

## 화면과 범위

좌하단 이동, 우하단 주먹, 우상단 가방을 둔다. 상단 중앙은 평상시 비운다. Wood/Stone은 재화가 아닌 재료이며 수량은 인벤토리에서만 확인한다. Food/영구 재화/고정 숫자 HUD는 제거했다. CanvasScaler 1920×1080과 Safe Area를 유지한다. 개발자 문구와 가짜 보스/테스트 버튼을 노출하지 않는다.

협동, 저장, 적 지속 생성/무한 생존 규칙, 장비/도구, 제작/건축, 장비창/상자/상세 능력치, 직업/성장, 실제 보스, 로그인/상점은 없다. 초기 수치는 BALANCE.md에 기록하며 출시 밸런스로 확정하지 않는다.
