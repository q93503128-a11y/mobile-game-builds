# Wildfolk 기획 정본

기준일: 2026-10-13. 실제 제공 기능은 main의 코드/데이터/씬을 기준으로 판단한다.

## 환경과 범위

Wildfolk는 Unity 6000.3.19f1 LTS / Universal 2D, 모바일 Landscape, 기준 1920×1080의 탑다운 생존 게임이다. 첫 플레이 버전에 원형 캐릭터 Facing, 9칸 Hotbar, 도끼/곡괭이를 추가한 단계다. 아트는 초기 시안이며 최종 아트가 아니다.

1~4인 협동, 무한 생존, 월드 저장 후 이어하기, 기지 생존은 지향점이며 미구현이다. 로그라이트 요소를 고려하되 영구 능력치 성장 비중은 낮게 잡고 직업별 특성을 고려한다. 네트워크/저장 형식/직업/성장 상세 규칙은 확정하지 않았다.

## 캐릭터 시각 언어

파란 천색 몸통 방향을 폐기했다. 기본 플레이어는 살구색 단순한 원형 몸체, 분리된 작은 원형 양손, 별도 눈 두 개다. 입/볼터치/코/동물 요소/옷 표현은 없다. 자연색, 무광 면, 절제된 외곽선과 접촉 그림자를 사용한다. 빵/병아리/석판/장난감 인상을 지양한다. 원형 몸체를 일반 캐릭터의 기본 언어로 삼는다.

기본 적은 탁한 회녹색 원형 Zombie다. 작은 어두운 눈과 절제된 얼룩/명암으로 플레이어와 구분한다. 고어/복잡한 인간형은 없다. 기존 AI/Health 구조를 유지한다.

몸통은 회전시키지 않는다. 공통 CharacterFacing이 눈과 양손을 방향 쪽으로 배치하고 좌우 관계를 유지한다. 공격 중은 공격 대상/공격 방향, 그 외 이동 중은 이동 방향, 정지하면 마지막 방향을 유지한다. 방향 변화는 짧은 각도 보간으로 표시한다. 손의 도구 위치/회전도 같은 방향 기준을 사용한다. 장비/머리 장식 부착 위치는 유지하며 실제 갑옷/모자/다른 무기는 없다.

## 현재 제공하는 기능

저장된 Wildfolk.unity에 플레이어, Zombie 1개, 나무 9개, 돌 6개, 연속 잔디/길과 자연 디테일을 배치했다. Orthographic Size 9, 부드러운 카메라 추적과 필드 경계 제한을 유지한다.

- Pointer Down/Drag/Up 아날로그 조이스틱, 대각선 이동, 중앙 복귀. 에디터 WASD/Space 보조 입력.
- PlayerCombat 하나로 맨손/도구를 처리한다. 가까운 대상을 선택하고 모션 중간에 범위를 재확인해 피해를 적용한다. 맨손은 양손 교대 확장, 도구는 오른손 중심 Arc 휘두름이다.
- 공통 Health/WorldHealthBar. 플레이어 항상 표시, 적/자원은 피해 후 표시, 사망/파괴 시 제거.
- 나무 흔들림, 돌의 단단한 흔들림, 생명체 flash/squash. 공용 타격 파티클 없음.
- 자원 파괴→바닥 Wood/Stone 3개→퍼짐/그림자/약한 bob→근접 획득. 공간 부족 시 수용량만 제거하고 잔량 유지.
- ItemDefinition/ItemStack/InventoryModel의 16슬롯. Wood/Stone 재료는 최대 스택 50, Axe/Pickaxe 도구는 최대 스택 1.
- Inventory 실제 슬롯 0~8 = Hotbar 표시 1~9. 데이터/선택을 복제하지 않는다. 아이템 획득 시 두 화면에 즉시 반영한다.
- Hotbar 슬롯 터치로 선택한다. 선택한 도구를 실제 오른손에 표시한다. 빈 슬롯/재료 선택은 맨손이다. 숫자키 선택은 구현하지 않았다.
- 인벤토리에서 Hotbar 9칸과 Storage 7칸을 분리해 보여주며 공유 선택을 강조한다. 인벤토리 열기/닫기, 일시 정지/입력 차단을 유지한다.
- 별도 StartingLoadout 설정으로 Axe 1/Pickaxe 1을 시작 지급한다. 첫 슬롯의 Axe가 기본 선택이다. 제작 도입 이후 지급 여부는 미정이다.
- ToolDefinition의 자원 종류별 효율 데이터로 도끼는 나무, 곡괭이는 돌에 효율적이다. 서로 반대 자원은 비효율적이다. 적 피해는 둘 다 맨손과 같은 초기 피해다.
- 적 감지→접근→정지→준비→명시적 피해→쿨다운→추적. Trigger/Kinematic, 겹침 해소는 적 자신만 이동, 플레이어 밀기/넉백 없음. HP 0 제거, 전리품 없음.
- 사망 후 새 필드 재시작. BossIdentity가 활성화될 때 이름/실제 HP를 상단 중앙에 표시하는 기반. 실제 보스 없음.

## UI/UX 방향과 제공하지 않는 것

Mine Survival/Minecraft 계열의 인벤토리·Hotbar·아이콘·장착 상태·최소 HUD 구조를 참고하되 고유 에셋/수치는 복제하지 않는다. surviv.io 계열은 단순한 원형 몸통/손/방향성 구조만 참고한다.

좌하단 Joystick, 하단 중앙 9칸 Hotbar, 우하단 공격/사용, 우상단 Inventory다. 상단 중앙은 보스가 없으면 비운다. Wood/Stone은 재료 아이템이며 상시 재화 HUD는 없다. CanvasScaler 1920×1080, Safe Area/Anchor를 사용한다. 게임 화면에 개발자 문구/테스트 UI/가짜 보스를 남기지 않는다.

협동·월드 저장·적 지속 생성·제작/건축·아이템 드래그/이동·도구 내구도·장비창/상자·직업/성장·실제 보스·로그인/상점은 미구현이다. 수치는 BALANCE.md의 초기값이며 재미/사용감은 사용자가 직접 테스트한다.
