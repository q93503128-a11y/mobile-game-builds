기준일: 2026-10-13. 사용자가 허용한 초기값이며 비교 게임 수치를 측정/복제하지 않았다. 재미와 세부 밸런스는 사용자가 플레이하면서 판단한다. 출시 밸런스로 확정하지 않는다. 단일 정본은 client/Assets/Wildfolk/Data/ 에셋이다.

적은 준비 시 정한 방향의 전방(dot > 0.4)과 사거리를 확인한다. 피격 반응은 0.16초, 나무 흔들림 0.075유닛/3도, 돌 0.038유닛/0.7도, 생명체 squash 최대 10%다. 아이템은 가득 찬 인벤토리에 대해 0.15초 간격으로 다시 획득을 시도한다.

EditMode는 양수 범위/거리 관계/드랍 지연, ID 중복/아이콘 참조, HP/드랍 수량, 자동 스택/한도/부분 수용/잘못된 입력을 검사한다. 확률 드랍·성장·경제·과금은 없다.

## 도끼/곡괭이

단일 정본: AxeTool.asset / PickaxeTool.asset. ItemDefinition이 ToolDefinition을 참조하고 ResourceDefinition.Kind와 효율 배열로 계산한다. 몬스터를 도구별 특화 전투 대상으로 만들지 않았다.

StartingEquipment.asset에서 Axe 1/Pickaxe 1을 시작 지급하고 슬롯 0의 Axe를 기본 선택한다. 이는 제작이 없는 현재 초기 장비 설정이며 제작 도입 후 유지 여부는 확정하지 않았다. 도구 내구도/소모/확률/강화 규칙은 없다. 정확한 수치는 초기 확인용이며 재미와 체감 밸런스는 사용자 테스트로 판단한다.
