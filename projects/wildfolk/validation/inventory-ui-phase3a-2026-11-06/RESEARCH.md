# Commercial Inventory UI Reference Study

Research is comparative, not a claim that one game's interface should be copied. Screenshots below are evidence for specific layout choices; they are not redistributed in the Lowfire prototype. Where a screenshot does not expose a build/platform, that uncertainty is retained.

## Decision trail

1. **Panel and grouping:** Necesse and Core Keeper both demonstrate distinct storage/equipment/hotbar roles in actual inventory views. Lowfire already has those three groups, but the mobile evidence shows them crowded together. The prototype labels and separates the same existing groups. We rejected adding category tabs or another storage screen because that would add unimplemented navigation and change how the current 36 slots are reached.
2. **Slots and selected item:** Core Keeper and Terraria screenshots make slot contents, quantity, and selection observable over a world scene. Lowfire's existing `InventorySlotView` already renders counts and waterskin charges. The prototype makes counts part of each slot and ties the selected outline to a stable details region. We rejected new rarity colors, item sorting, and synthetic iconography because no such data/actions are present in Lowfire's source.
3. **Touch actions:** Terraria Mobile's actual split control shows why an action should be explicit and near inventory context. Lowfire supports stack splitting, drag-move, drag-to-ground, and equipment drops. We show only these actions and their current states. We rejected persistent extra buttons and a scroll/paging affordance because those would imply behavior that is not implemented.
4. **World and art harmony:** Don't Starve and the two top-down pixel survival games keep their game-specific item/world art present around UI. Lowfire's reference background and item sprites remain actual Lowfire assets. New UI is a restrained dark-forest utility surface with an ember primary action; no external art or texture was copied. We rejected a parchment/hand-drawn treatment because it conflicts with Lowfire's current 2D art.
5. **Item detail correctness:** Mobile Don't Starve screenshots demonstrate survival-specific item state, but Lowfire's code is authoritative: show the source-backed sword values and charge count, and omit durability because no such field exists. We rejected extrapolating detail fields from reference games.

## Source quality and limits

- The Necesse screenshot and guides are community wiki materials; their version metadata is explicit only for upload date/resolution, not game build/platform. Use the official Steam page for developer, release date, and product context, not to authenticate that old screenshot as 1.0 UI.
- Core Keeper and Don't Starve Together images are user-submitted screenshots, not official UI spec sheets. The official Steam pages confirm product/developer context only.
- Terraria's wiki screenshot and mobile controls page are the most version-specific evidence in this comparison.
- The Don't Starve Pocket app listing is official, while the screenshot showing its inventory is third-party and version-unknown.
- No referenced screenshot, icon, texture, layout, or title treatment was copied into the Lowfire art files.
