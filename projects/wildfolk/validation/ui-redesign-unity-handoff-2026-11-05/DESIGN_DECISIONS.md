# 디자인 결정 — 요소별 유지/개선/재제작/제외

## 결론

방향 C의 화면 시야와 행동 위계, A의 읽기 쉬운 상태·표면 구분, B의 아이템 슬롯 명료도를 결합합니다. 결과는 기존 시안의 합성 복제본이 아니라 Lowfire 고유의 절제된 숲 생존 UI입니다. 실제 적용 색/크기/비율은 파일럿에서 다국어와 기기 화면을 거쳐 조정해야 합니다.

상태 의미:
- **KEEP** — 기존 리소스 또는 원칙을 그대로 유지합니다.
- **REFINE** — 큰 방향은 유지하고 가독성·간격·반응형을 다듬습니다.
- **REBUILD** — 필요 기능/개념은 유지하되 구성 또는 그래픽을 다시 만듭니다.
- **DISCARD** — 최종 시스템에서 사용하지 않습니다. 콘텐츠 동작을 삭제한다는 뜻은 아닙니다.

## 비교 근거

A — Forest Utility는 정보 블록과 상태 표시가 읽히지만 인벤토리 표면의 밝은 면적이 크고 장면을 덮습니다.
B — Crafted Survival은 슬롯·장비의 물질감이 생존 제작과 어울리지만 어두운 패널이 무겁고 공통 테두리가 반복됩니다.
C — Modern Adventure는 열린 월드와 큰 주 행동이 좋지만 얇고 투명한 윤곽, 844 상태/XP 충돌, 작은 글자가 문제입니다.
Stage 1.5 메뉴는 844 배치의 패널 밀도를 줄였지만, 1280·1920은 빈 하단이 과하고 싱글플레이 이름/설명이 겹치며 멀티플레이가 동등한 주 CTA처럼 보여 새 게임 의미를 흐립니다. 그러므로 Stage 1.5도 승인이 완료된 디자인으로 취급하지 않습니다.

## 반드시 보존할 제품 의미

- Continue는 검증된 현재 싱글플레이 세이브를 이어갑니다. 새 게임은 새 랜덤 월드 생성이며 기존 월드가 있을 때 H02 교체 확인을 거칩니다.
- 현재 다중 월드 선택기는 없습니다. Penpot 시안의 지도 아이콘은 상용 기능 근거가 아닙니다.
- 인벤토리와 제작 UI가 열린 동안 세계 진행은 계속됩니다. 싱글플레이 Pause와 사망은 멈춥니다. 멀티플레이 일시정지 의미는 서버 권한/현재 동작을 따릅니다.
- 멀티플레이는 LAN Host/Join 및 별도 Host 저장 파일을 사용합니다. 서버 탐색기/Host migration을 UI만으로 암시하지 않습니다.
- 상점/광고는 현재 비활성/승인 게이트를 따릅니다. 가짜 구매 동작을 시안에 넣지 않습니다.

## 해결 우선순위

1. 작은 HUD 글자와 현재 상태 그룹의 시각적 우선순위.
2. 두 엄지 사용에서 공격/상호작용/대시 간 움직임과 오입력.
3. 844×390 인벤토리에서 36칸과 선택 상세 정보의 읽기 흐름.
4. 한글/영문에서 같은 기능 라벨의 겹침·축소·잘림.
5. 메타/멀티플레이 상태를 과장하지 않는 메뉴/오류 표현.
