# 2-C 작업 시간·공유 사용량

모든 시각 KST(UTC+9),2026-10-21. 단계 시간은 서로 겹치지 않는다. 토큰·작업별 정확한 사용량은 API에 없으며 계정 공용5시간/주간 반올림 비율만 관측했다. 다른 채팅 사용이 포함될 수 있다.

Git 최종 commit/push/remote 확인 종료 시각·총 경과는 최종 보고와 workspace `sidegrade-completion.json`에 남긴다. 이 문서가 포함되는 commit의 자기 SHA를 미리 기록하지 않는다.

## 측정 가능한 도구/프로세스 대기

아래는 각 프로세스 전체 wall time이며 그 동안 문서/실제 Unity/다른 도구를 병행했다. 단계 경과에 다시 더하지 않는다. compilation/asset import/Unity startup/종료를 포함하며 테스트 자체 duration과 다르다.

|도구/프로세스|시작 KST|wall time|테스트 자체 duration|
|---|---|---:|---:|
|git fetch origin main|최초 실행|1.901초|해당없음|
|EditMode 초기65|09:36:17.796|53.367초|2.337초|
|PlayMode 관련5|09:37:42.242|231.497초|182.958초|
|EditMode sink 기대값 교정3|09:42:04.581|34.501초|0.057초|
|기존 근접 추가 회귀2|09:42:52.951|57.579초|22.057초|

Unity refresh의 비동기 compile/reload와 개별 MCP 호출 전체 대기 합계는 별도 정확한 timer를 두지 않아 합산하지 않았다. 실제 SP/Host fixture는 `live-mcp.tsv`,headless는`headless-play.tsv`의UTC시각으로 구분한다.

최종 diff 정리·검토: 09:46:36→09:48:20, 1분44초. 09:48:20 commit 직전 공용 사용량5시간65%/주간26%, 직전 관측 대비+3/+0pp, 시작 대비+25/+3pp다. 토큰·개별 작업 비용으로 환산하지 않는다.
