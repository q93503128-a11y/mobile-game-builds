## Design system decided before implementation

Use existing woodland/camp/field-paper identity and Noto Sans KR, with forest ink/olive, warm paper and restrained ember. One dominant ember primary, bordered paper secondary, muted navigation, underlined/link-like tertiary; danger uses dark rust and explicit words. No universal pale-grey rectangle. Selected tabs receive olive fill/ink rule; disabled actions remain legible but subdued; no lock for mere currency/point shortage. Notification marks only reflect actionable existing rewards.

Authored1920×1080 reference: spacing8/16/24/40/64; title42–48, body32–36, caption28–30; essential action height120–132 and minimum110 hit area after fitting, audited in actual844×390 output. Paper panels have a fine ink edge, shallow offset shadow and no text crossing decorative binding. Cards group icon/title/progress/next reward; reward tile distinguishes real Gem from visit stamp. Modal keeps title/body/cancel/primary together; destructive modal explains cloud/account/economy/support deletion, kept local worlds and minimal financial-record retention policy without invented legal periods. Empty states say why and offer a relevant available action, not a large dead claim button. Detail-on-selection serves as a touch tooltip; do not require hover.

Home: one clear Play decision (Continue only with a valid save; otherwise New Game). Class remains play preparation; Profile, Achievements and Attendance get distinct direct entries. Account remains inside Profile; Store is a small Gem/balance entry. Keep camp illustration clear of navigation and separate chest/fire. Meta uses one paper sheet, avoids seam-crossing forms, uses scroll only where content requires it. MP separates Create/Join intent; room state replaces idle fields; Class is removed from MP while admission truth is preserved.

Attendance retains7/28/catalog rewards and server claim rules; show catalogue preview when offline, with explicit unavailable state and no false claimability. Achievement retains22/58/7, family cards and next target rather than58duplicated cards. Class summaries derive from actual catalog/player mechanics. Trees draw actual prerequisites within padded graph bounds; learned/selected/prerequisite lock/budget shortage are separate.

Controls: floating base within broad left-safe-area zone, first pointer owns until up/cancel/focus loss/modal; deadzone and clamped knob; no overlapping hotbar/menu raycasts. Right attack strongest, dash/interact secondary; desktop adapter retained. Loading uses actual transition phases without false percentage and existing network failures/cancellation. Water/creature changes require actual visual, import/prefab and history evidence; no arbitrary art revert or speed/balance changes.
