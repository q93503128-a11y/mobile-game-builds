# Lowfire Inventory Unity Pilot — Phase 4A

## Status

**IMPLEMENTED:** The canonical inventory builder and the single-player/multiplayer scenes now use the brown, flat 2D inventory treatment, four equipment rows, 9-slot hotbar, 27-slot storage grid, live selection details, and localized equipment status.

**TESTED:** Seven targeted Unity PlayMode regression tests passed on Unity `6000.3.19f1` after scene regeneration.

**UNVERIFIED:** No rendered Unity Game View PNG was obtained. The visual layout, text fit, KO/EN appearance, and touch targets have not received the required on-screen or Android-device review. This pilot is not visually approved.

## What changed

- `client/Assets/Wildfolk/Editor/InventoryUiBuilder.cs` is the canonical layout and nine-slice authoring path.
- `client/Assets/Wildfolk/Runtime/UI/InventoryPanel.cs` refreshes selected-item live text independently.
- `client/Assets/Wildfolk/Runtime/UI/InventoryEquipment.cs` displays the four equipment slots, candidate/equipped/empty state, selection, and existing equip/unequip actions.
- Existing content and boss equipment authoring paths delegate to the canonical equipment builder.
- `Wildfolk.unity` and `Multiplayer.unity` were regenerated by `Wildfolk/Refresh Inventory Pilot Scenes`.
- Five 9-slice PNGs and their editable SVG sources are included.

No item definitions, recipes, save/profile/protocol schema, economy, or multiplayer authority were changed. No user's save was used by the PlayMode tests.
