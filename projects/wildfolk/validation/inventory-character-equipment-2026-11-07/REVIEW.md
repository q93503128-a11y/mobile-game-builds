# Lowfire Inventory Character & Equipment Visual Revision

**상태:** 미승인 정적 시안. Unity 구현 금지 범위 준수.

## 기준과 범위

- 작업 시작 시 `mobile-game-builds/main`: `b9773712123585ddd827cfb2065349dc9f1f7ab0`
- 작업 시작 시 `dev-playbook/main`: `e022e9e4ff3947fcbd7f5b0237c5905d7c0409c7`
- 두 저장소의 `main`을 재확인해도 각각 같은 SHA였다.
- Phase 3D의 갈색 프레임과 나머지 인벤토리 화면을 유지하고 장비 표현부만 비교했다.
- 핫바 9칸, 보관함 27칸, 장비 4종과 기존 선택 아이템 `강철 투구`를 보존했다.
- 새 이미지/Unity 소스/씬/데이터/세이브/네트워크 코드는 수정하지 않았다. 기존 아트와 Phase 3D 시안은 읽기 전용으로 사용했다.

## 실제 캐릭터 구조와 확대 한계

현재 플레이어는 전신 일러스트가 아니다. `GameplayActorBuilder`는 `player_body.png` 피부 베이스, 분리된 양손, 눈 두 개를 조립하며 장비 오버레이를 추가한다. 소스 크기는 피부 베이스 160×160, 눈 32×32, 손 64×64, 머리/몸 오버레이 150×150, 손 오버레이 34×38이다. Unity 런타임 구성에 몸통 또는 다리 스프라이트가 없다. 기존 플레이 화면 캡처에서도 캐릭터는 헬멧을 쓴 둥근 머리와 분리된 손/도구로 보인다.

따라서 현재 원본으로는 사용자가 요청한 **전신형**을 만들 수 없다. 몸통이나 다리를 임의로 그리거나 정면 초상화를 합성하지 않았다.

## A/B/기존 비교

| 안 | 화면 표현 | 읽기/공간 평가 | 한계 및 판정 |
|---|---|---|---|
| 기존 Phase 3D | 플레이어 얼굴을 약 130px 원본 영역에서 56px 원형으로 잘라 장비 소켓 가운데 배치 | 캐릭터와 4개 장비 소켓의 위계가 분리되고, 머리 확대가 강하다 | 사용자가 승인하지 않은 얼굴 확대 방식. 전신 착용 관계를 보여주지 못함 |
| A — 실제 월드 시점 캐릭터 | 기존 Lowfire 게임 캡처의 270×220 월드 영역을 110×90 장비 영역으로 축소. 체력바를 제외하고 현재 캐릭터/주변 지면을 그대로 표시. 원형 마스크와 가짜 몸통 없음 | 캐릭터가 게임 월드 안에서 쓰이는 실제 비율에 가까워졌고, 화면 장면과 아트가 동일함 | 결과가 여전히 머리·손 중심의 작은 탑다운 리그다. 장비 소켓을 실제 몸 부위에 자연스럽게 연결할 전신이 없으며, A의 전신 요구에 **불합격**. 참고용 한계 증명으로만 보존 |
| B — 캐릭터 없는 장비 레일 | 캐릭터를 제거하고 연속된 세로 연결선/노드/행 구분으로 Head, Body, Utility, Accessory를 한 장비 영역으로 묶음 | 네 종류와 장착 상태를 한 번에 읽고, 선택된 Head 교체 대상은 점선 녹색 행으로 구별. 분리된 네 사각형 나열보다 장비 집합이라는 관계가 분명함 | 844×390에서 분류/상태 라벨과 하단 해제 안내가 작다. 레일 구조는 유지하되 실제 Unity 적용 전 1:1 터치 가독성 검토가 필요 |

비교 PNG의 순서는 **왼쪽 기존 얼굴 확대 → 가운데 A → 오른쪽 B**다.

## B의 장착/교체/해제 정보

- 머리: 현재 `철 투구`, 선택 대상 `강철 투구`, `교체` 상태와 녹색 선택 행.
- 몸: `철 보호구`, `착용`.
- 보조 장비: `랜턴`, `착용`.
- 장신구: `미장착`, `비어 있음`.
- 오른쪽 기존 아이템 세부 패널은 `강철 투구`, 방어력 `2 → 3`, `장착` 버튼을 표시한다. 현재 철 투구와 슬롯 선택으로 장착 해제하는 경로도 짧은 안내로 표시한다.
- 이들은 현재 인벤토리 기능을 표현한 정적 시안이다. 실제 버튼 입력이나 장착/해제 동작을 시험한 것은 아니다.

## 모바일 가독성 및 공간 사용

- 두 후보 모두 844×390 PNG로 출력해 픽셀 크기와 화면 전체를 확인했다. 공통 핫바 9칸, 보관함 27칸, 장비 4칸은 그대로 보인다.
- 장비 영역은 기존 208×176 패널을 사용한다. A와 B는 패널 경계, 아이콘, 선택 행, 세부 패널과 겹치거나 화면 밖으로 잘리지 않았다.
- 최종 B의 슬롯 이름은 9.4px, 분류 라벨은 8.2px, 상태 라벨은 8.6px다. 세부 패널의 해제 안내는 8.5px, 장비 레일 하단 안내는 8px다. 첫 렌더보다 작은 라벨을 키웠지만, 휴대전화에서 편하게 읽히는 크기라고 단정하려면 실제 기기 확인이 필요하다.
- 기존 화면의 보관함 하단 여백은 약 5px로 남아 있다. 이는 이 작업에서 바꾸지 않은 Phase 3D 레이아웃의 기존 한계다.
- 언어 범위는 요청대로 한국어 한 해상도뿐이다. 영어/다른 해상도, 실제 휴대전화, 터치 목표 크기 및 Unity Game View는 확인하지 않았다.

## 시각 검수 및 재현

- A와 B를 각각 844×390으로 렌더링하고, 기존 화면+A+B를 2532×390 비교 PNG로 합쳤다.
- Edge headless SVG 렌더링을 사용했다. 렌더 결과를 1:1로 직접 확인했으며 A는 전신 부재와 얼굴 중심 잔존, B는 작은 라벨 가독성을 확인했다.
- 재현 명령: 저장소 루트에서 `./projects/wildfolk/art-source/inventory-character-equipment-2026-11-07/render_previews.ps1`
- 이 결과는 정적 시안 검수다. Unity 컴파일, EditMode/PlayMode, 실제 게임의 입력/장착/세이브 회귀는 실행하지 않았다.
- 외부 이미지나 폰트/아이콘을 추가하지 않았다. 기존 Lowfire 리포지토리 아트와 화면 캡처만 참조했다.

## 추천

**B를 다음 검토 후보로 추천한다.** 캐릭터 초상화를 억지로 맞추지 않으며 장비 종류·아이템·교체 상태를 더 직접적으로 제시한다. 다만 작은 분류/상태 텍스트는 아직 승인 전 보정이 필요하다. A는 현재 게임에 전신 아트가 없다는 사실을 드러내는 비교 자료이며, 승인 가능한 전신 시안으로 간주하면 안 된다. 더 나은 A가 필요하면 게임 아트 팀이 탑다운 실루엣에 맞는 몸통/다리 연결 표현을 별도 제작한 뒤 재평가해야 한다.
